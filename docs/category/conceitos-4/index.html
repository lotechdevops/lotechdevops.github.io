Conceitos Amazon S3

Conceitos fundamentais sobre o Amazon S3

📄️ 1. Introdução ao S3

O que é o Amazon S3, conceitos de bucket, objeto e chave, principais características, limites, formas de acesso, modelo de cobrança e casos de uso.

📄️ 2. Classes de Armazenamento

As classes de armazenamento do S3 (Standard, IA, Intelligent-Tiering e Glacier), preços, tempos mínimos de permanência e como escolher a classe certa.

📄️ 3. Versionamento

Como o versionamento mantém várias versões de um objeto, o que é um delete marker, os benefícios, os custos e o MFA Delete.

📄️ 4. Replicação

Replicação entre buckets na mesma Region (SRR) ou em Regions diferentes (CRR), regras de funcionamento, limitações, custos e Replication Time Control.

📄️ 5. Políticas de Acesso

IAM policies, bucket policies e ACLs, exemplos com condições (IP, HTTPS, criptografia, Organization) e a ordem de avaliação das permissões.

📄️ 6. Block Public Access e Ownership

Como o Block Public Access evita buckets públicos por engano e como o Object Ownership desabilita as ACLs e define o dono dos objetos.

📄️ 7. Criptografia

Criptografia em trânsito e em repouso no S3: SSE-S3, SSE-KMS, SSE-C e criptografia no lado do cliente, com casos de uso de cada modelo.

📄️ 8. Object Lock e MFA Delete

Como proteger objetos contra exclusão e alteração com o S3 Object Lock (modelo WORM), os modos Governance e Compliance, o Legal Hold e o MFA Delete.

📄️ 9. Sites Estáticos

Como hospedar um site estático no S3, requisitos de acesso público, limitações do endpoint (somente HTTP), integração com domínio e custos.

📄️ 10. URLs Pré-assinadas e CORS

Como compartilhar objetos privados com URLs pré-assinadas e como configurar o CORS para que navegadores acessem o S3 a partir de outros domínios.

📄️ 11. Lifecycle

Regras de Lifecycle para mover objetos entre classes e excluí-los automaticamente, escopo por prefixo e tag, versões não atuais e detalhes de custo.

📄️ 12. Storage Class Analysis

Como o Storage Class Analysis analisa os padrões de acesso aos objetos e ajuda a decidir quando criar regras de transição de classe.

📄️ 13. Requester Pays

Como o Requester Pays transfere para quem faz a requisição o custo de requisições e de download, e quando usar para compartilhar grandes datasets.

📄️ 14. Event Notifications

Como o S3 envia eventos para SNS, SQS, Lambda e EventBridge, as permissões necessárias em cada destino e os casos de uso.

📄️ 15. Performance

Desempenho do S3: baseline por prefixo, Multipart Upload, Transfer Acceleration e Byte-Range Fetches.

📄️ 16. Batch Operations

Como executar ações em massa sobre milhões de objetos com um único job, usando S3 Inventory para definir a lista de objetos.

📄️ 17. Inventory e Consistência

Como o S3 Inventory lista os objetos de um bucket em relatórios agendados e o que significa a consistência forte de leitura após gravação.

📄️ 18. Storage Lens

Como o S3 Storage Lens oferece visibilidade de uso, custo e proteção de dados, os tipos de métricas e as diferenças entre o plano gratuito e o avançado.

📄️ 19. Access Points

Como os S3 Access Points criam pontos de acesso dedicados, com DNS e policy próprios, para simplificar permissões em buckets compartilhados.

📄️ 20. Object Lambda

Como o S3 Object Lambda transforma objetos em tempo de resposta com funções Lambda, sem alterar o original armazenado no bucket.
