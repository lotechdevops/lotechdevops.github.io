Configuração ConfigMap e Secret via Variáveis de Ambiente

Objetivo do Lab​

Demonstrar como configurar uma aplicação no Kubernetes que consome valores sensíveis (Secrets) e configurações não sensíveis (ConfigMaps) através de variáveis de ambiente.

Configurações ConfigMap​

1. Criar o ConfigMap​

  • Crie um arquivo chamado app-configmap.yaml com o seguinte conteúdo:
apiVersion: v1
kind: ConfigMap
metadata:
  name: app-config
data:
  APP_ENV: "production"
  APP_DEBUG: "false"
  • Aplique o ConfigMap no cluster com:
kubectl apply -f app-configmap.yaml

2. Criar o Pod que consome o ConfigMap via variáveis de ambiente​

  • Crie um arquivo chamado pod-app.yaml com o seguinte conteúdo:
apiVersion: v1
kind: Pod
metadata:
  name: app-env-pod
spec:
  containers:
  - name: app-container
    image: busybox
    command: [ "/bin/sh", "-c", "env && sleep 3600" ]
    env:
    - name: APP_ENV
      valueFrom:
        configMapKeyRef:
          name: app-config
          key: APP_ENV
    - name: APP_DEBUG
      valueFrom:
        configMapKeyRef:
          name: app-config
          key: APP_DEBUG
  • Aplique o arquivo no cluster com o comando:
kubectl apply -f pod-app.yaml

3. Teste​

Você pode verificar se as variáveis foram inseridas no Pod com o comando:

kubectl exec -it app-env-pod -- env | grep APP_

Saída esperada:

APP_DEBUG=false
APP_ENV=production

Configurações Secret​

1. Criar a Secret​

  • Crie um arquivo chamado app-secret.yaml com o seguinte conteúdo:
apiVersion: v1
kind: Secret
metadata:
  name: app-secret
type: Opaque
data:
  DB_USER: YWRtaW4=        
  DB_PASSWORD: c2VuaGE=
  • Aplique o ConfigMap no cluster com:
kubectl apply -f app-secret.yaml

2. Criar o Pod que consome a Secret via variáveis de ambiente​

  • Crie um arquivo chamado pod-app-secret.yaml com o seguinte conteúdo:
apiVersion: v1
kind: Pod
metadata:
  name: app-env-pod-secret
spec:
  containers:
  - name: app-container
    image: busybox
    command: [ "/bin/sh", "-c", "env && sleep 3600" ]
    env:
    - name: DB_USER
      valueFrom:
        secretKeyRef:
          name: app-secret
          key: DB_USER
    - name: DB_PASSWORD
      valueFrom:
        secretKeyRef:
          name: app-secret
          key: DB_PASSWORD
  • Aplique o arquivo no cluster com o comando:
kubectl apply -f pod-app-secret.yaml

3. Teste​

Você pode verificar se as variáveis foram inseridas no Pod com o comando:

kubectl exec -it app-env-pod-secret -- env | grep DB

Saída esperada:

DB_USER=admin
DB_PASSWORD=senha
