Expondo Aplicações com Cloudflare Tunnel

Visão Geral​

Nesta etapa, você aprenderá como expor aplicações do Kubernetes de forma segura, gratuita e sem necessidade de IP público fixo utilizando o Cloudflare Tunnel (também conhecido como cloudflared).

Essa abordagem é especialmente útil para:

  • Ambientes on-premises.
  • Clusters locais com CGNAT ou IP dinâmico.
  • Garantir acesso externo sem abrir portas no roteador.

O que é o Cloudflare Tunnel​

O Cloudflare Tunnel é uma solução que permite expor serviços locais para a internet de forma segura, sem precisar abrir portas e sem depender de IP fixo.

O agente cloudflared cria uma conexão segura de dentro para fora com a Cloudflare, permitindo que usuários externos acessem seus serviços privados por meio de um túnel HTTPS autenticado.

O que será feito​

Você irá:

  1. Criar um Tunnel no painel Cloudflare Zero Trust.
  2. Implantar o agente cloudflared no cluster Kubernetes.
  3. Criar uma Published Application Route para a aplicação.

Pré-requisitos​

  • Domínio configurado na Cloudflare
  • Acesso ao painel Cloudflare Zero Trust
  • Ingress-NGINX e MetalLB já configurados.
  • Certificado TLS válido (ou "No TLS Verify" habilitado).
  • Serviço da aplicação acessível via MetalLB.

Instalação e Configuração do Cloudflare Tunnel​

1. Criar o Tunnel​

  • 1.1. Acesse Zero Trust da Cloudflare
  • 1.2. Vá em Networks -> Tunnels
  • 1.3. Clique em Add a Tunnel
  • 1.4. Escolha Cloudflared, dê um nome e clique em Save Tunnel
  • 1.5. Copie o TUNNEL_TOKEN que a Cloudflare mostrar (vamos usar no Kubernetes).

2. Instalação do cloudflared​

  • 2.1 - Crie um namespace para o Cloudflared
kubectl create ns cloudflare-tunnel

  • 2.2 - Instale o cloudflared

  • Crie uma secret no cluster com o Token do Tunnel

kubectl -n cloudflare-tunnel create secret generic cloudflared \
  --from-literal=TUNNEL_TOKEN='<COLE_AQUI_O_TUNNEL_TOKEN>'
  • Crie um deployment do cloudflared
apiVersion: apps/v1
kind: Deployment
metadata:
  name: cloudflared
  namespace: cloudflare-tunnel
spec:
  replicas: 1
  selector:
    matchLabels: 
        app: cloudflared
  template:
    metadata:
      labels:
        app: cloudflared
    spec:
      containers:
      - name: cloudflared
        image: cloudflare/cloudflared:latest
        args: ["tunnel", "--no-autoupdate", "run"]
        env:
        - name: TUNNEL_TOKEN
          valueFrom:
            secretKeyRef:
              name: cloudflared
              key: TUNNEL_TOKEN
  • Aplique o deployment no cluster
kubectl apply -f deploy-tunnel.yaml
  • Confere se conectou
kubectl -n cloudflare-tunnel logs deploy/cloudflared | tail -n 50

3. Criar um Published Application​

Depois que o túnel estiver Healthy, você precisa configurar uma rota de acesso para sua aplicação no painel da Cloudflare:

  • 3.1 - Acesse o menu Tunnels
  • 3.2 - Selecione o seu Tunnel e clique em Configure
  • 3.3 - Vá até a aba Published application route
  • 3.4 - Clique em Add a Published Application Route:
  • 3.4 - Preencha os campos da seguinte forma:
    • Hostname:
      • Subdomain -> O subdomínio que irá acessar sua aplicação (ex: prometheus)
      • Domain -> Seu domínio principal (ex: devopsr66.com)
      • Path -> Caminho (opcional) para a aplicação. Se não souber, deixe /
    • Service:
      • Type -> Escolha HTTPS(se seu ingress usa TLS).
      • URL -> IP do serviço do Ingress exposto pelo MetalLB (ex: 192.168.123.233)
