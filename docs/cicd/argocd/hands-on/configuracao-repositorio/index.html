Configuração do Repositório Git

Objetivo​

Conectar o ArgoCD ao seu repositório Git, permitindo que ele acesse os manifests das aplicações que serão implantadas nos próximos passos.

Esse passo é essencial para que o ArgoCD consiga sincronizar o estado do Git com o cluster Kubernetes.

Entendendo o papel do repositório​

O repositório Git é a fonte única da verdade (Single Source of Thuth) para todo o estado do cluster. Cada alteração feita no repositório, seja atualização de imagem, réplicas ou labels, será aplicada automaticamente pelo ArgoCD.

O ArgoCD monitora constantemente o repositório e executa o ciclo:

Git -> Detecta mudança -> Sincroniza -> Aplica no cluster

Formas de autenticação suportadas​

O ArgoCD permite várias formas de autenticação com o Git:

| Tipo                    | Descrição                               | Cenário ideal                                  |
| ----------------------- | --------------------------------------- | ---------------------------------------------- |
| SSH                     | Usa chaves pública/privada              | Repositórios privados e ambientes corporativos    |
| HTTPS + Token           | Usa Personal Access Token (PAT)         | Projetos simples ou laboratórios               |
| GitHub App / OAuth      | Integração direta com GitHub Enterprise | Organizações grandes                           |
| GCP Source Repositories | Autenticação automática do GCP          | Ambientes GKE                                  |

No nosso exemplo, usaremos autenticação via SSH, que é o método mais seguro e independente.

Configurações​

1. Gerando a chave SSH​

Crie um novo par de chaves SSH em sua máquina

ssh-keygen -t ed25519 -C "argocd@devopsr66" -f ~/.ssh/argocd
  • -t ed25519 -> gera uma chave moderna e mais segura.
  • -C -> adiciona um comentário (identificação).
  • -f -> define o nome do arquivo.

Isso criará dois arquivos:

~/.ssh/argocd      ← chave privada
~/.ssh/argocd.pub  ← chave pública

2. Adicionando a chave pública ao GitHub​

  1. Acesse seu repositório -> Settings -> Deploy Keys -> Add deploy key
  2. No campo Title, coloque:
    • ArgoCD Access Key
  3. No campo Key, cole o conteúdo da sua chave pública gerada: 
    cat ~/.ssh/argocd.pub
  4. Marque a opção Allow write access (opcional, apenas se quiser permitir sincronização bidirecional).
  5. Clique em Add key.

​

3. Adicionando o repositório Git ao ArgoCD UI​

  1. Acesse o painel do ArgoCD -> Settings -> Repositories.
  2. Clique em Connect Repo
  3. Selecione a opção VIA SSH

Aparecerá o formulário para conexão do repositório.

Preencha os campos da seguinte forma:

  • Name -> Este campo é opcional para repositórios Git, mas obrigatório para repositórios Helm. Ele serve apenas como um identificador interno para facilitar o gerenciamento.
ex.: infra

  • Project -> Define se o repositório será global (usado por todos os projetos) ou restrito a um AppProject específico

    Para o nosso laboratório GitOps, deixe esse campo em branco, pois o repositório será global

  • Repository URL -> É o endereço SSH do repositório Git que contém os manifests das suas aplicações.

ex.: git@github.com:lotechdevops/infra.git
  • SSH Private Key -> cole aqui o conteúdo da sua chave privada SSH, criada anteriormente.
ex.: cat ~/.ssh/argocd

Clique em Connect.

Se a configuração estiver correta, você verá a mensagem:

Connection status: Successful

Você também pode validar via CLI:

argocd repo list

Saída esperada:

TYPE  NAME   REPO                                     STATUS     MESSAGE
git   infra  git@github.com:lotechdevops/infra.git   Successful
