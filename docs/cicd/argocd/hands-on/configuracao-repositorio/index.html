Configuração do Repositório Git

Objetivo​

Conectar o ArgoCD ao seu repositório Git, permitindo que ele acesse os manifestos das aplicações que serão implantadas nos próximos passos.

Esse ponto é essencial para que o ArgoCD consiga sincronizar o estado do Git com o cluster Kubernetes.

Entendendo o papel do repositório​

O repositório Git é a fonte única da verdade (Single Source of Truth) para todo o estado do cluster.

Cada alteração feita no repositório será aplicada automaticamente pelo ArgoCD:

  • Atualização de imagem
  • Mudança de reṕlicas
  • Alteração de labels
  • Novos recursos

O ArgoCD monitora constantemente o repositório e executa o ciclo:

Git (mudança) → ArgoCD detecta → Compara com cluster → Sincroniza → Aplica

Formas de autenticação suportadas​

O ArgoCD permite várias formas de autenticação:

TipoDescriçãoCenário ideal
SSHUsa chaves pública/privadaRepositórios privados, mais seguro
HTTPS + TokenUsa Personal Access Token (PAT)Projetos simples, laboratórios
HTTPS + User/PassUsuário e senhaNão recomendado (menos seguro)
GitHub AppIntegração OAuth com GitHubGitHub Enterprise
GCP Source RepositoriesAutenticação automática do GCPAmbientes GKE

Neste guia, mostraremos SSH e HTTPS com Token.

Método 1: Autenticação via SSH (Recomendado)​

1.1. Gerando a chave SSH​

Crie um novo par de chaves SSH em sua máquina:

ssh-keygen -t ed25519 -C "argocd@devops" -f ~/.ssh/argocd

Parâmetros:

  • -t ed25519 -> Algoritmo moderno e seguro
  • -C -> Comentário (identificação)
  • -f -> Caminho e nome do arquivo

Isso criará dois arquivos:

~/.ssh/argocd      ← chave privada (NUNCA compartilhe!)
~/.ssh/argocd.pub  ← chave pública (adicionar no Git)

1.2. Adicionando a chave pública ao GitHub​

Para repositórios específicos (Deploy Key):

  1. Acesse seu repositório no GitHub
  2. Settings -> Deploy Keys -> Add deploy key
  3. No campo Title, coloque: ArgoCD Access Key
  4. No campo Key, cole o conteúdo de ~/.ssh/argocd.pub
  5. Allow write access -> Deixe desmarcado (ArgoCD só precisa ler)
  6. Clique em Add key

1.3. Adicionando o repositório Git ao ArgoCD (UI)​

  1. Acesse o painel do ArgoCD -> Settings -> Repositories
  2. Clique em Connect Repo
  3. Selecione VIA SSH

Preencha os campos:

CampoValorDescrição
Nameinfra (opcional)Identificador interno (obrigatório só para Helm repos)
Project(vazio)Deixe vazio para ser global, ou selecione um Project específico
Repository URLgit@github.com:usuario/repo.gitURL SSH do repositório
SSH Private Key(cole a chave privada)Conteúdo do arquivo ~/.ssh/argocd
  1. Clique em Connect

Validação bem-sucedida:

Connection Status: Successful

1.4. Validar via CLI​

argocd repo list

Método 2: Autenticação via HTTPS + Token​

2.1. Gerar Personal Access Token (GitHub)​

  1. Acesse GitHub -> Settings -> Developer settings
  2. No menu esquerdo, clique em Personal access tokens -> Tokens (classic) -> Generate new token
  3. Selecione as permissões:
    • repo (Full control of private repositories)
  4. Generate token
  5. Copie o token (você não verá novamente)

2.2. Adicionar repositório via HTTPS no ArgoCD (UI)​

  1. Settings -> Repositories
  2. Clique em Connect Repo
  3. Selecione VIA HTTPS
  4. Preencha os campos:
CampoValor
Typegit
Nameinfra-https (opcional)
Project(vazio)
Repository URLhttps://github.com/usuario/repo.git
UsernameSeu username do GitHub
PasswordCole o Personal Access Token

2.3. Adicionar repositório via CLI (HTTPS)​

argocd repo add https://github.com/usuario/repo.git \
  --username seu-usuario \
  --password ghp_xK8j2mR5nP3qL9wTyH4vB6nM1sQ7pA9c

Com SSH:

argocd repo add git@github.com:usuario/repo.git \
  --ssh-private-key-path ~/.ssh/argocd

Método 3: Repositório Helm​

O ArgoCD também pode conectar a repositórios Helm para instalar charts.

3.1. Adicionar repositório Helm Público via HTTPS no ArgoCD (UI)​

  1. Settings -> Repositories -> Connect Repo
  2. Selecione VIA HTTPS
  3. Type: helm

Exemplo:

CampoValor
Namebitnami (obrigatório para Helm!)
Typehelm
Project(vazio)
Repository URLhttps://charts.bitnami.com/bitnami

3.2. Adicionar repositório Helm Público via CLI (HTTPS)​

argocd repo add https://charts.bitnami.com/bitnami \
  --type helm \
  --name bitnami

3.3. Adicionar repositório Helm Privado (com autenticação) via UI​

  1. Settings -> Repositories -> Connect Repo
  2. Selecione VIA HTTPS
  3. Digite Name
  4. Type: helm

Conclusão​

Neste lab você aprendeu:

  • Conectar repositórios Git via SSH
  • Conectar repositórios via HTTPS + Token
  • Validar conexões

Agora o ArgoCD pode acessar seus manifestos!
