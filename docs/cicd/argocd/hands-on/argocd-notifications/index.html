Configurando o ArgoCD Notifications

Objetivo​

O ArgoCD Notifications é o componente responsável por enviar alertas e notificações automáticas sobre eventos que ocorrem nas Applications do ArgoCD, como sucesso, falha, sincronização, ou degradação.

O ArgoCD pode integrar com as seguintes ferramentas de comunicação como:

  • Slack
  • Microsoft Teams
  • E-mail
  • Webhook
  • Opsgenie, PagerDuty, entre outros.

Visão Geral do ArgoCD Notifications​

O componente argocd-notifications-controller observa os objetos Applicatione envia alertas baseados em triggers (gatilhos) e templates (mensagens).

Fluxo simplificado

Application → Trigger → Template → Slack Bot (via token OAuth)

Com isso, o ArgoCD notifica automaticamente eventos como:

  • Sucesso de deploy
  • Falha de sincronização
  • Aplicação degradada
  • Aplicação fora de sync

Estrutura básica​

O Notifications funciona a partir de três blocos principais:

  1. Service (Destinatário) -> Define para onde a notificação vai (ex: Slack, e-mail, webhook).
  2. Template -> Define o conteúdo da mensagem (ex: título, texto, status da aplicação).
  3. Trigger -> Define quando a notificação será enviada (ex: ao sincronizar, falhar ou degradar).

Configuração​

No nosso exemplo criaremos uma notificação via Slack.

1. Criar um App no Slack​

  1. Acesse https://api.slack.com/apps
  2. Clique em Create New App -> From Scratch
  3. Dê um nome (ex: ArgoCD Notifications) e selecione o Workspace (ex: devopsr66)
  4. Clique em Create App

2. Configurar OAuth e Permissons​

  1. Vá em OAuth & Permissions
  2. Em Scopes -> Bot Token Scopes
  3. Clique em Add an OAuth Scope e adicione as permissões:
  • chat:write
  • groups:read
  1. Role a tela para o início e Clique em Install to Workspace
  2. Na aba que abrirá clique em Install ArgoCD Notifications
  3. Volte para a aba principal e copie o Bot User OAuth Token (ele começa com xoxb-)

3. Adicionar o bot ao canal Slack​

No Slack, no canal desejado, execute:

/invite @ArgoCD Notifitions

Ou adicione o app via Canal, clique em View channel details -> Integrations -> Add apps.

4. Obter o Channel ID​

  1. Clique no nome do canal
  2. Vá em View channel details
  3. Role até o final e copie o Channel ID (ex: C09N78FRM44)

Esse ID será usado nas annotations das aplicações

5. Criar a Secret com o Token do Slack​

  1. Transforma o token em base64
echo -n <COLE-O-TOKEN-AQUI> | base64
  1. Crie o arquivo argocd-notifications-secret.yaml com o token do slack em base64.
apiVersion: v1
kind: Secret
metadata:
  name: argocd-notifications-secret
  namespace: argocd
data:
  slack-token: <COLE-O-TOKEN-AQUI>

Aplicar no cluster:

kubectl apply -f argocd-notifications-secret.yaml

  # Triggers
  trigger.on-deployed: |
    - when: app.status.operationState.phase in ['Succeeded'] and app.status.health.status == 'Healthy'
      send: [app-deployed]

  trigger.on-sync-running: |
    - when: app.status.operationState.phase in ['Running']
      send: [app-sync-running]

  trigger.on-sync-failed: |
    - when: app.status.operationState.phase in ['Error', 'Failed']
      send: [app-sync-failed]

  trigger.on-health-degraded: |
    - when: app.status.health.status == 'Degraded'
      send: [app-health-degraded]

  trigger.on-out-of-sync: |
    - when: app.status.sync.status == 'OutOfSync'
      send: [app-out-of-sync]

Aplicar no cluster:

kubectl apply -f argocd-notifications-cm.yaml

7. Adicionar as anotações na Application​

Agora, conecte uma Application (por exemplo: nginx-dev) ao sistema de notificações.

Edita a aplicação e adicione as annotations.

apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: nginx-dev
  namespace: argocd
  annotations:
    notifications.argoproj.io/subscribe.on-sync-succeeded.slack: "C09N78FRM44"
    notifications.argoproj.io/subscribe.on-sync-failed.slack: "C09N78FRM44"
    notifications.argoproj.io/subscribe.on-health-degraded.slack: "C09N78FRM44"
    notifications.argoproj.io/subscribe.on-out-of-sync.slack: "C09N78FRM44"
    notifications.argoproj.io/subscribe.on-deployed.slack: "C09N78FRM44"
spec:
  ...

Essas anotações dizem ao ArgoCD:

"Quando esse evento acontecer, envie a notificação para o canal Slack chamado argocd-alertas (C09N78FRM44)".

Reinicia o pod do controller

kubectl delete pod -n argocd -l app.kubernetes.io/name=argocd-notifications-controller

5. Testar o envio das mensagens​

  1. Faça uma alteração no Git que gere uma nova sincronização.
  2. Aguarde o ArgoCD sincronizar.
  3. Observe os logs do controller:
kubectl logs -n argocd deploy/argocd-notifications-controller | grep slack
