Instalação

Este laboratório mostra como instalar o ArgoCD em um cluster Kubernetes.

Pré-requisitos​

  • Cluster Kubernetes funcional (on-premises ou em nuvem).
  • Kubectl configurado para acessar o cluster.

1. Criar namespace do ArgoCD​

O ArgoCD deve rodar em seu próprio namespace:

kubectl create namespace argocd

2. Instalar o ArgoCD​

Aplicar os manifests de instalação:

kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml

Essa instalação inclui todos os componentes principais:

  • argocd-server -> API e interface web.
  • argocd-repo-server -> clona e interpreta manifests do Git.
  • argocd-application-controller -> aplica e reconcilia estados.
  • argocd-dex-server -> autenticação (SSO).
  • argocd-notifications-controller -> notificações.
  • argocd-redis -> cache de estado.

3. Verificar se os pods foram criados​

Confirme se todos os pods estão rodando:

kubectl get pods -n argocd

Você deve ver algo como:

argocd-application-controller-xxxxx   Running
argocd-application-set-controller-xxxxx Running
argocd-dex-server-xxxxx              Running
argocd-notifications-controller-xxxxx Running
argocd-redis-xxxxx                   Running
argocd-repo-server-xxxxx             Running
argocd-server-xxxxx                  Running

4. Acessar a interface web​

Por padrão, o ArgoCD expõe o argocd-server como um Service do tipo ClusterIP.

Para acessar localmente, faça um port-forward:

kubectl port-forward svc/argocd-server -n argocd 8080:443

Agora a UI estará acessível em:

http://localhost:8080

5. Obter a senha inicial​

O usuário padrão do ArgoCD é admin.

A senha inicial é armazenada em um Secret Kubernetes criado durante a instalação.

Para exibir a senha:

kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d && echo

Use esse valor para logar na UI.

6. Instalar a CLI do ArgoCD​

Para facilitar o uso, instale a CLI no Linux:

# Baixar a versão estável
curl -sSL -o argocd https://github.com/argoproj/argo-cd/releases/latest/download/argocd-linux-amd64

# Dar permissão de execução
chmod +x argocd

# Mover para o PATH
sudo mv argocd /usr/local/bin/

Valide a instalação:

argocd version

7. Fazer login via CLI​

argocd login localhost:8080 --username admin --password <SENHA_INICIAL> --insecure

Use -insecure se estiver usando HTTPS sem certificado válido.

Agora você pode interagir com o ArgoCD sem precisar da UI.

8. Verificar a comunicação via CLI​

argocd app list

Mesmo sem Applications criadas, o comando deve funcionar, isso confirma que a CLI e o servidor estão conectados.

9. Expor ArgoCD via Ingress-NGINX (Opcional)​

Se já houver Ingress instalado:

apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: argocd
  namespace: argocd
  annotations:
    kubernetes.io/ingress.class: "nginx"
spec:
  rules:
    - host: argocd.lab.local
      http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: argocd-server
                port:
                  number: 443
  tls:
    - hosts:
        - argocd.lab.local
      secretName: argocd-tls

Conclusão​

Neste hands-on você:

  • Instalou o ArgoCD no Kubernetes.
  • Acessou a UI e a CLI

Você agora possui todos os componentes prontos para iniciar o fluxo GitOps e criar os próximos recursos:

  1. Conectar o repositório Git
  2. Criar o Project
  3. Criar a Application
