Criação do Project no ArgoCD

Objetivo​

Neste etapa, você vai criar um Project no ArgoCD chamado prometheus para organizar as aplicações de observabilidade do cluster.

Pré-requisitos

  • ArgoCD instalado e acessível
  • Acesso ao cluster Kubernetes
  • Repositório Git configurado.

Passo 1: Decidir o método de criação​

Vamos usar o método YAML declarativo, pois é o mais alinhado com práticas GitOps e permite versionamento.

Se preferir testar primeiro pela interface, as seções de UI e CLI também estão disponíveis.

Passo 2: Criar o arquivo do Project​

Crie o arquivo prometheus-project.yaml com a seguinte configuração:

apiVersion: argoproj.io/v1alpha1
kind: AppProject
metadata:
  name: prometheus
  namespace: argocd
spec:
  description: Projeto de Observabilidade - Prometheus e Alertmanager
  
  # Repositórios permitidos
  sourceRepos:
    - git@github.com:lotechdevops/apps-argocd.git
    - https://prometheus-community.github.io/helm-charts
  
  # Destinos permitidos
  destinations:
    - namespace: observabilidade
      server: https://kubernetes.default.svc
    - namespace: kube-system
      server: https://kubernetes.default.svc
  
  # Recursos permitidos
  clusterResourceWhitelist:
    - group: '*'
      kind: '*'
  
  namespaceResourceWhitelist:
    - group: '*'
      kind: '*'
  
  # Alertas sobre recursos órfãos
  orphanedResources:
    warn: true

Passo 3: Aplicar o Project​

kubectl apply -f prometheus-project.yaml

Saída esperada:

appproject.argoproj.io/prometheus created

Passo 4: Verificar a criação​

Via kubectl

kubectl get appproject prometheus -n argocd

Saída esperada:

Via ArgoCD CLI

argocd proj get prometheus

Saída esperada:

Passo 5: Visualizar no ArgoCD UI​

  1. Acesse o ArgoCD UI
  2. Navegue até Settings -> Projects
  3. Você deve ver o Project prometheus listado

Alternativa: Criação via ArgoCD UI​

Se preferir criar pela interface gráfica:

Passo a Passo​

  1. Acesse Settings -> Projects -> New Project
  2. Preencha os campos:
  • Project Name -> prometheus
  • Description -> Projeto de Observabilidade - Prometheus e Alertmanager
  1. Em Source Repositories, adicione:
  • git@github.com:lotechdevops/apps-argocd.git
  • https://prometheus-community.github.io/helm-charts
  1. Em Destinations, adicione:
  • Server: https://kubernetes.default.svc -> Namespace: observabilidade
  • Server: https://kubernetes.default.svc -> Namespace: kube-system
  1. Em Cluster Resource Allow List e Namespace Resource Allow List:
  • Group: *
  • Kind: *
  1. Clique em Create

Alternativa: Criação via CLI​

Se preferir usar a linha de comando:

argocd proj create prometheus \
  --description "Projeto de Observabilidade - Prometheus e Alertmanager" \
  --src git@github.com:lotechdevops/apps-argocd.git \
  --src https://prometheus-community.github.io/helm-charts \
  --dest https://kubernetes.default.svc,observabilidade \
  --dest https://kubernetes.default.svc,kube-system \
  --allow-cluster-resource '*/*' \
  --allow-namespace-resource '*/*'

Comandos úteis​

  • Listar todos os projects
argocd proj list
  • Ver detalhes completos de um project
argocd proj get prometheus
  • Editar um project via CLI
argocd proj edit prometheus
  • Editar via kubectl
kubectl edit appproject prometheus -n argocd
  • Adicionar repositório ao project
argocd proj add-source prometheus https://github.com/user/repo.git
  • Remover repositório do project
argocd proj remove-source promethus https://github.com/user/repo.git
  • Adicionar destino ao project
argocd proj add-destination prometheus https://kubernetes.default.svc namespace-name
  • Deletar um project
argocd proj delete prometheus

Você só pode deletar um project se não houver Applications associados a ele.

Próximos passos​

Agora que o Project está criado, você pode:

  1. Criar Applications dentro deste project
  2. Configurar permissões RBAC conforme necessário
  3. Adicionar mais repositórios conforme necessário
  4. Configurar Roles para controle de acesso por equipe
