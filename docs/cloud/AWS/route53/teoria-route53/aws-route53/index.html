Introdução Route 53

O que é o Route 53​

O Amazon Route 53 é um serviço de DNS (Domain Name System) altamente disponível e escalável da AWS.

Ele pode ser usado de forma combinada ou separada para três funções principais

  • Registro de Domínios
  • Roteamento de Tráfego DNS
  • Verificação de Integridade

Funções principais do Route 53​

1. Registro de Domínios​

  • Permite registrar nomes de domínios, como por exemplo example.com, para uso em sites e aplicações.
  • Pode ser feito diretamente no Route 53 ou com outro registrador.

2. Roteamento de Tráfego DNS​

  • Direciona usuários que acessam seu domínio (example.com ou app.example.com) para o recurso correto na AWS ou fora dela.
  • Pode rotear o tráfego para:
    • EC2
    • S3
    • Load Balancers
    • Serviços externos
  • Recursos relacionais:
    • Configurar o Route 53 como DNS principal
    • Roteamento de e-mails para Amazon WorkMail

3. Verificação de Integridade​

  • Executa verificações automáticas para confirmar se seus recursos estão:
    • Acessíveis
    • Disponíveis
    • Funcionando corretamente
  • Pode enviar alertas e redirecionar tráfego caso um recurso esteja indisponível

Outros Recursos do Route 53​

Route 53 Resolver​

  • Serviço de DNS recursivo para:
    • Amazon VPC na AWS
    • AWS Outposts
    • Rede on-premises
  • Permitir criar regras de encaminhamento condicional e endpoints para resolver nomes internos ou externos.

Route 53 Resolver no Outposts​

  • Integra racks do AWS Outposts com servidores DNS locais.
  • Permite resolução de nomes entre ambientes on-premises e AWS.

Firewall de DNS (Route 53 Resolver DNS Firewall)​

  • Protege consultas DNS recursivas.
  • Permite criar listas de domínios e regras para bloquear ou permitir tráfego DNS de saída.

Fluxo de Tráfego (Traffic Flow)​

  • Ferramenta de gerenciamento de tráfego global.
  • Permite rotear usuários para o endpoint mais adequado considerando:
    • Latância
    • Integridade
    • Geolocalização
    • Geoproximidade

Perfis do Route 53​

  • Aplicam e gerenciam configurações de DNS do Route 53 em múltiplas VPCs e contas AWS.

Conclusão​

O Route 53 é mais do que apenas um serviço DNS. Ele combina registro de domínios, roteamento inteligente e verificações de integridade, além de oferecer recursos avançados como DNS Resolver, Firewall de DNS e Traffic Flow, tornando-o uma solução completa para gerenciar e proteger o tráfego de internet de aplicações.
