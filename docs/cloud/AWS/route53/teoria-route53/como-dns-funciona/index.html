Como funciona o DNS

A imagem abaixo ilustra o funcionamento do DNS, um processo essencial para transformar nomes de domínio (como example.com) em endereços IP utilizáveis (por exemplo: 9.10.11.12) pelos navegadores.

Esse fluxo é conhecido como resolução de nomes DNS

Etapas do Processo​

1. Web Browser -> Local DNS Server​

  • O usuário digita example.com no navegador.
  • O navegador envia uma requisição DNS para o servidor DNS local.
  • Se esse servidor já tiver a resposta em cache (respeitando o TTL), ele retorna o IP diretamente.
  • Caso não tenha a resposta, inicia-se o processo recursivo de resolução.

2. Local DNS -> Root DNS Server​

  • O servidor local pergunta: "Quem sabe onde está example.com"?
  • O Root DNS Server não sabe o IP final, mas responde com o endereço do TLD DNS Server responsável por .com.

Gerenciado pela ICANN - organização que supervisona os domínios raiz da internet.

3. Local DNS -> TLD DNS Server (.com)​

  • O servidor local agora consulta o TLD DNS Names para .com, perguntando novamente sobre example.com
  • O TLD responde com o endereço dos servidores DNS autoritativos (Name Servers) do domínio.

Gerenciado pela IANA, uma divisão da ICANN responsável pelos TLDs.

4. Local DNS -> SLD DNS Server (Authoritative DNS)​

  • O Local DNS consulta o servidor autorizado (SLD DNS Server), que efetivamente gerencia o domínio example.com
  • Esse servidor retorna o endereço IP final (9.10.11.12) onde o site está hospedado.

Pode ser gerenciado por serviços como o Amazon Route 53, Google DNS, Cloudflare, etc.

5. Local DNS -> Web Browser​

  • O IP (9.10.11.12) é retornado ao navegador.
  • O navegador agora pode estabelecer conexão com o servidor e exibir o site.

Resumo​

| Etapa | Consulta                       | Resposta                                    |
| ----- | ------------------------------ | ------------------------------------------- |
| 1     | Navegador → DNS local          | "Qual o IP de `example.com`?"               |
| 2     | DNS local → Root               | "Qual servidor responde pelo TLD `.com`?"   |
| 3     | DNS local → TLD                | "Qual servidor responde por `example.com`?" |
| 4     | DNS local → SLD (Autoritativo) | "O IP de `example.com` é `9.10.11.12`"      |
| 5     | DNS local → Navegador          | IP retornado e site acessado                |

Essa é a base do funcionamento do DNS tradicional, o Amazon Route 53 entra como o servidor DNS autoritativo (etapa 4), caso você esteja usando a AWS para gerenciar seu domínio.
