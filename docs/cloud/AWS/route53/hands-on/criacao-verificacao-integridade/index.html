Criação das Verificações de Integridade

Tipos de Health Checks​

Demonstrar a criação dos 3 tipos de Health Checks no Route 53:

  1. Verificação por Endpoint (ex: Instância EC2)
  2. Verificação Calculada (baseada em outras checagens)

1. Verificação por Endpoint​

Objetivo​

Criar um Health Check no Route 53 para monitorar se uma instância EC2 está online e respondendo por HTTP.

Script​

O script abaixo simular um servidor HTTP rodando nas instâncias EC2.

#!/bin/bash
yum update -y
yum install -y httpd
INSTANCE_ID=$(curl http://169.254.169.254/latest/meta-data/instance-id)
AZ=$(curl http://169.254.169.254/latest/meta-data/placement/availability-zone)
echo "<h1>Instância: $INSTANCE_ID - Zona de Disponibilidade: $AZ</h1>" > /var/www/html/index.html
systemctl enable httpd
systemctl start httpd

Etapas de Configuração Básica​

  1. Acesse o console do Amazon Route 53 em https://console.aws.amazon.com/route53/
  2. No meu lateral esquerdo, clique em Verificações de integridade
  3. Clique em Criar verificação de integridade
  4. Preencha os campos:
    • Nome: Escolha um nome descritivo para sua verificação de integridade.
    • Recurso: Selecione a opção Endpoint
    • Especificar endpoint por: Selecione a opção Endereço IP
    • Protocolo: Selecione a opção HTTP ou HTTPS, conforme o serviço configurado na EC2.
    • Endereço IP: Digite o IP da instância EC2 (Ex: 192.0.2.44:80/).

      Substitua pelo IP público da sua instância EC2 e o path desejado. Se for apenas /, deixe como mostrado acima.

Etapas de Configuração Avançadas​

  1. Intervalo de solicitações: Define com que frequência o Route 53 enviará uma requisição para verificar a integridade do endpoint.
    • Padrão (30 segundos): Uma verificação a cada 30 segundos (mais econômico).
    • Rápido (10 segundos): Três vezes mais frequente (custo adicional).

Para testes, o padrão já é suficiente. Para ambientes críticos, o modo rápido é recomendado.

  1. Limite de falha: Número de falhas consecutivas necessárias para o endpoint ser considerado não íntegro.

    • Exemplo: Valor 3 -> Se 3 verificações consecutivas falharem, o status será marcado como "fora do ar".

  2. Correspondência de string (opcional): Permite validar a resposta do endpoint com base no conteúdo da página.

    • Se você digitar por exemplo OK nesse campo, a resposta da página deve conter exatamente esse texto nos primeiros 5120 bytes do corpo da resposta HTTP.
    • Útil para validar que o serviço está funcionando corretamente, e não apenas online.

  3. Gráficos de latância (opcional): Habilita gráficos para você visualizar a latência das requisições de verificação.

    Essa opção não pode ser desativada depois de criada a verificação.

  4. Inverter status da verificação de integridade: Usado para simular falhas manualmente.

    • Se marcado, quando a verificação estiver OK, ela será interpretada como "com problema".
    • Pode ser útil em testes de failover controlado.

  5. Desabilitar verificação de integridade: Se marcada, o Route 53 irá pausar a verificação sem excluir a configuração.

    • Muito útil em ambientes de homologação ou em manutenção temporária.

  6. Regiões do verificador de integridade: Você pode selecionar até 8 regiões da AWS diferentes para executar as verificações.

    • Recomendado marcar pelo menos 3 regiões, distribuídas globalmente.
    • Isso garante maior confiabilidade e resiliência contra falhas regionais.

  7. Nome do host (opcional): Define o valor do cabeçalho Host usado na requisição HTTP feita pelo health check.

    • Por padrão, o IP é usado como host.
    • Se seu servidor espera um Host específico para responder corretamente (ex: example.com), informe aqui.

2. Verificação Calculada​

Objetivo​

Criar uma verificação de integridade que monitore o status de duas ou mais verificações de integridade existentes, e determine a integridade com base em uma lógica definida (ex: "todas devem estar íntegras" ou "pelo menos uma").

Etapas de Configuração​

  1. Acesse o console do Amazon Route 53 em https://console.aws.amazon.com/route53/
  2. No meu lateral esquerdo, clique em Verificações de integridade
  3. Clique em Criar verificação de integridade
  4. Preencha os campos:
    • Nome: Escolha um nome descritivo para sua verificação de integridade.
    • Recurso: Selecione a opção Verificação de integridade calculada
    • Verificações de integridade a serem monitoradas: selecione duas ou mais verificações de integridade do tipo Endpoint já criadas.
    • Informar como íntegra quando: Escolha o comportamento desejado para o resultado:
      • Todas as verificações de integridade estão íntegras: A verificação calculada só será considerada íntegra se todas as verificações selecionadas estiverem OK.
      • Um número mínimo de verificações de integridade que devem ser consideradas íntegras: Permite definir um número mínimo.
  5. Após configurar os campos, clique em Criar verificação de integridade.
