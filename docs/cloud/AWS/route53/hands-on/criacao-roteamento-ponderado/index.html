Criação do Roteamento Ponderado

Objetivo​

Configurar o Route 53 para distribuir o tráfego entre três instâncias EC2 em diferentes regiões com pesos diferentes.

Pré-requisitos​

  1. Zona hospedada pública já criada no Route 53
  2. 3 instâncias EC2 com IP público, uma em cada região listada abaixo.
  3. O mesmo script será usado para todas as instâncias via campo User Data.

Script​

#!/bin/bash
yum update -y
yum install -y httpd
INSTANCE_ID=$(curl http://169.254.169.254/latest/meta-data/instance-id)
AZ=$(curl http://169.254.169.254/latest/meta-data/placement/availability-zone)
echo "<h1>Instância: $INSTANCE_ID - Zona de Disponibilidade: $AZ</h1>" > /var/www/html/index.html
systemctl enable httpd
systemctl start httpd

Neste exemplo, utilizamos instâncias EC2 criadas com um script no campo User Data, que retorna uma página identificando a instância e a região onde está rodando.

Instâncias utilizadas​

| Região       | IP Público       | Peso |
| ------------ | ---------------- | ---- |
| us-east-1    | `184.73.71.148`  | 30   |
| us-west-1    | `54.193.224.61`  | 30   |
| ca-central-1 | `35.182.250.172` | 30   |

Etapas de Configuração​

  1. Acesse o console do Amazon Route 53 em https://console.aws.amazon.com/route53/

  2. Vá até sua zona hospedada pública e clique em Criar registro

  3. Preenche os campos:

    • Nome do registro: ponderado

      Isso criará o domínio: ponderado.devopsr66.com

    • Tipo de Registro: A - Endereço IPv4

  4. Crie os três registros com o seguintes dados:

    • Primeiro registro (us-east-1)

      • Valor IPv4: 184.73.71.148
      • Peso: 30
      • ID do registro: us-east-1
      • TTL: 15 segundos
      • Política de roteamento: Ponderado
      • Clique em Adicionar outro registro para adicionar mais um registro.

    • Segundo registro (us-west-1)

      • Valor IPv4: 54.193.224.61
      • Peso: 30
      • ID do registro: us-west-1
      • TTL: 15 segundos
      • Política de roteamento: Ponderado
      • Clique em Adicionar outro registro para adicionar mais um registro.

    • Terceiro registro (ca-central-1)

      • Valor IPv4: 35.182.250.172
      • Peso: 30
      • ID do registro: ca-central-1
      • Política de roteamento: Ponderado
      • TTL: 15 segundos

  5. Clique em Criar registros

Testes​

Após criar os registros ponderado, você pode testar a resolução DNS no terminal utilizando o comando curl em um loop.

i=1
while true; do
  echo -n "[$i] "
  curl -s http://ponderado.devopsr66.com | grep Instância
  sleep 1
  ((i++))
done

Saída esperada

[1] <h1>Instância: i-0c7c5d3ff49825161 - Zona de Disponibilidade: us-east-1a</h1>
[2] <h1>Instância: i-0c7c5d3ff49825161 - Zona de Disponibilidade: us-east-1a</h1>
[3] <h1>Instância: i-07e9be13f34a142c5 - Zona de Disponibilidade: ca-central-1a</h1>
[4] <h1>Instância: i-0ef6f1d6b331dee9d - Zona de Disponibilidade: us-west-1b</h1>

Isso permite identificar claramente qual instância respondeu a requisição, e de qual AZ ela veio.

Se os pesos forem diferentes, o retorno de cada IP será proporcional ao valor atribuído no registro.
