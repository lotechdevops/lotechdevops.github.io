Como o Amazon Route 53 verifica a integridade dos seus recursos

As verificações de integridade do Amazon Route 53 monitoram a integridade dos seus recursos, como servidores Web e servidores de e-mail. Opcionalmente, você pode configurar alarmes do CloudWatch para receber notificações quando um recurso ficar indisponível.

Processo de Verificação de Integridade​

1. Configuração da Verificação​

Você cria uma verificação de integridade especificando:

  • Endpoint: Endereço IP ou nome de domínio do recurso a ser monitorado.
  • Protocolo: HTTP, HTTPS ou TCP para realizar a verificação.
  • Intervalo de Solicitação: Frequência das verificações.
  • Limite de Falha: Número de falhas consecutivas antes de considerar o recurso não íntegro.
  • Notificações: Configuração opcional via CloudWatch e Amazon SNS.

2. Monitoramento Contínuo​

O Route 53 envia solicitações regulares para o endpoint no intervalo especificado. Se o endpoint responde normalmente, é considerado íntegro e nenhuma ação é tomada.

3. Detecção de Falhas​

Quando o endpoint não responde, o Route 53 inicia uma contagem de falhas consecutivas:

  • Se a contagem atinge o limite de falha configurado, o endpoint é marcado como não íntegro.
  • Se o endpoint volta a responder antes do limite, a contagem é zerada.

3. Sistema de Notificações​

Quando um endpoint é considerado não íntegro:

  • Se configurado, o Route 53 notifica o CloudWatch.
  • O CloudWatch aciona um alarme e usa o Amazon SNS para enviar notificações.
  • Mesmo sem notificações, o status pode ser monitorado pelo console do Route 53.

Tipos Avançados de Verificação​

Verificação Calculada​

Você pode configurar verificações que avaliam o estado de múltiplas outras verificações de integridade, permitindo notificações quando um número específico de recursos (como 2 de 5 servidores web) estão indisponíveis.

Verificações de Alarme CloudWatch​

Monitore o status de alarmes CloudWatch, permitindo notificações baseadas em uma ampla variedade de critérios além da simples resposta a solicitações.

Failover de DNS​

Para recursos que executam a mesma função (servidores web, bancos de dados), você pode configurar failover de DNS associando verificações de integridade a cada registro. Quando uma verificação determina que um recurso não está íntegro, o Route 53 automaticamente desvia o tráfego para recursos saudáveis, garantindo alta disponibilidade da aplicação.
