Lab 02: Criar e Consumir Fila FIFO

Objetivo do Lab​

Neste laboratório você vai criar uma fila FIFO do Amazon SQS, enviar mensagens com Message Group ID e Deduplication ID, e verificar na prática como a ordem é estritamente garantida e duplicatas são impossíveis.

O que você vai aprender:

  • Criar fila FIFO via console AWS
  • Configurar Content-Based Deduplication
  • Enviar mensagens com Message Group ID
  • Enviar mensagens com Deduplication ID
  • Verificar ordem FIFO garantida
  • Testar deduplicação (Janela de 5 minutos)
  • Comparar com comportamento de fila standard
  • Deletar fila

Custo estimado: GRATUITO (Free Tier: 1 milhão requisições/mês)

1.1 Acessar Console SQS​

  • Faça login no console AWS
  • Na barra de busca, digite SQS
  • Clique em Simple Queue Service

1.2 Criar Nova Fila​

  • Clique em Create queue

1.3 Configurar Tipo de Fila​

  • Em Type, selecione FIFO
Diferença Visual

Ao selecionar FIFO, novas opções aparecerão: Content-based deduplication, High throughput FIFO queue, Deduplication scope, FIFO throughput limit.

1.4 Configurar Nome​

  • Em Name, digite meu-lab-fifo-queue.fifo
Nome Obrigatório .fifo

O nome de filas FIFO DEVE terminar com .fifo. Sem isso, a criação falhará.

1.5 Configurar Settings Básicas​

  • Em Configuration, mantenha as configurações:
    • Visibility timeout: 30 seconds
    • Message retention period: 4 days
    • Delivery delay: 0 seconds
    • Maximum message size: 1024 KiB (1 MB)
    • Receive message wait time: 20 seconds (long polling habilitado)

1.6 Configurar Content-Based Deduplication​

  • Em Content-Based deduplication, habilite
O Que É Content-Based Deduplication?

Quando habilitado, o SQS calcula automaticamente um hash SHA-256 do corpo da mensagem para deduplicação. Você NÃO precisa fornecer Message Deduplication ID manualmente.

1.7 Configurar Throughput​

Opção A: Modo Padrão (3.000 msg/s)

  • Deixe DESMARCADO: "High throughput FIFO queue"
  • Deduplication scope: Queue (automaticamente selecionado)
  • FIFO throughput limit: Per queue (automaticamente selecionado)

Opção B: Modo Alto Throughput (70.000 msg/s) - Opcional

Se quiser experimentar alto throughput:

  • Marque: "High throughput FIFO queue
  • As opções abaixo ficam DESABILITADAS (configurações automática):
    • Deduplication scope: Automaticamente configurado para "Message group"
    • FIFO throughput limit: Automaticamente configurado para "Per message group ID"
Por Que Ficam Desabilitados?

Quando você habilita alto throughput, a AWS automaticamente configura essas opções para os valores necessários. Você não pode mudá-las porque são requisitos técnicos para atingir 70K msg/s.

Para este lab: Use Opção A (modo padrão) - 3.000 msg/s é mais que suficiente para aprendizado.

1.8 Configurações de Acesso​

  • Em Access policy, mantenha Basic
  • Define who can send messages to the queue: Only the queue owner
  • Define who can receive messages from the queue: Only the queue owner

1.9 Configurações Adicionais​

  • Encryption: Desabilitado
  • Dead-letter queue: Desabilitado
  • Redrive allow policy: Desabilitado
  • Tags: Opcional

1.10 Criar Fila​

  • Role até o final da página
  • Clique em Create queue
  • Você verá mensagem de sucesso

Passo 2: Enviar Mensagens com Message Group ID​

2.1 Acessar Opção de Enviar Mensagem​

  • Na página de detalhes da fila, clique em Send and receive messages

2.2 Enviar Primeira Mensagem​

  • Em Message body, digite:
{
  "orderId": "001",
  "action": "create_order",
  "customer": "João Silva",
  "amount": 150.00
}
  • Em Message group ID, digite: order-group-1
Message Group ID Obrigatório

Em filas FIFO, o Message Group ID é obrigatório. Mensagens do mesmo grupo são processadas em ordem FIFO.

  • Em Message deduplication ID: Deixe vazio (estamos usando content-based deduplication)
  • Clique em Send message

2.3 Enviar Mais Mensagens do Mesmo Grupo​

Envie mais 4 mensagens do mesmo grupo (order-group-1):

Mensagem 2:

{
  "orderId": "001",
  "action": "process_payment",
  "customer": "João Silva",
  "amount": 150.00
}
  • Message group ID: order-group-1

Mensagem 3:

{
  "orderId": "001",
  "action": "prepare_shipment",
  "customer": "João Silva",
  "amount": 150.00
}
  • Message group ID: order-group-1

Mensagem 4:

{
  "orderId": "001",
  "action": "ship_order",
  "customer": "João Silva",
  "amount": 150.00
}
  • Message group ID: order-group-1

Mensagem 5:

{
  "orderId": "001",
  "action": "notify_customer",
  "customer": "João Silva",
  "amount": 150.00
}
  • Message group ID: order-group-1

Ordem Crítica

Essas mensagens representam fluxo de pedido:

  1. Criar pedido
  2. Processar pagamento
  3. Preparar envio
  4. Enviar pedido
  5. Notificar cliente

A ordem DEVE ser mantida!

2.4 Verificar Estastísticas​

  • Volte para a página principal de Queues
  • Na listagem, você verá:
    • Messages available: 5
    • Messages in flight: 0

Passo 3: Receber Mensagens e Verificar Ordem​

3.1 Acessar Opção de Poll​

  • Clique em Send and receive messages
  • Role até a seção Receive messages

3.2 Fazer Poll​

  • Clique eu Poll for messages

3.3 Observar Mensagens Recebidas​

  1. create_order
  2. process_payment
  3. prepare_shipment
  4. ship_order
  5. notify_customer

Ponto crítico para observar:

  • As mensagens aparecem EXATAMENTE na ordem que você enviou
  • create_order SEMPRE aparece primeiro
  • notify_customer SEMPRE aparece por último
Ordem FIFO Garantida

Diferente de filas Standard (que podem vir fora de ordem), filas FIFO garantem ordem estrita. As mensagens sempre aparecem na sequência: 1 → 2 → 3 → 4 → 5
