Lab 01: Criar e Consumir Fila Standard

Objetivo do Lab​

Neste laboratório você vai criar uma fila Standard do Amazon SQS, enviar mensagens via console, receber e processar mensagens, e entender na prática o comportamento de entrega "at-least-once" e ordenação "best-effort".

O que você vai aprender:

  • Criar fila Standard via console AWS
  • Enviar mensagens para a fila
  • Receber e visualizar mensagens
  • Configurar visibility timeout
  • Entender duplicatas ocasionais
  • Testar ordenação de mensagens
  • Deletar fila

Custo estimado: Gratuito (Free Tier: 1 milhão requisições/mês)

Passo 1: Criar Fila Standard​

1.1 Acessar Console SQS​

  • Faça login no console AWS
  • Na barra de busca, digite SQS
  • Clique em Simple Queue Service

1.2 Criar Nova Fila​

  • Clique em Create queue

1.3 Configurar Tipo de Fila​

  • Em Type, selecione Standard

1.4 Configurar Nome e Detalhes​

  • Em Name, digite: meu-lab-standard-queue
  • Em Configuration, mantenha as configurações padrão, exceto em Receive message wait time
    • Visibility timeout: 30 seconds
    • Message retention period: 4 days
    • Delivery delay: 0 seconds
    • Meximum message size: 1024 KiB (1 MB)
    • Em Receive message wait time, altere para 20 seconds (Isso habilita long polling e reduz custos)
Long Polling

Long polling reduz o número de chamadas vazias à API, economizando custos e melhorando eficiência.

1.6 Configurações de Acesso​

  • Em Access policy, mantenha Basic
  • Define who can send messages to the queue: Only the queue owner
  • Define who can receive messages from the queue: Only the queue owner

1.7 Configurações Adicionais (Opcional)​

  • Encryption: Desabilitado
  • Dead-letter queue: Desabilitado
  • Redrive allow policy: Desabilitado (não vamos usar esta fila como DLQ)
  • Tags: Opcional (pode adicionar caso necessário)

1.8 Criar Fila​

  • Role até o final da página
  • Clique em Create queue

Você verá mensagem de sucesso e será redirecionado para os detalhes da fila.

1.9 Copiar URL da Fila​

  • Na página de detalhes, você verá URL da fila
  • Copie a URL (será algo como: https://sqs.us-east-1.amazonaws.com/123456789012/meu-lab-standard-queue)

Passo 2: Enviar Mensagens para a Fila​

2.1 Acessar Opção de Enviar Mensagem​

  • Na página de detalhes da fila, clique em Send and receive messages (canto superior direito)

2.2 Enviar Primeira Mensagem​

  • Em Message body, digite:
{
  "orderId": "001",
  "customer": "João Silva",
  "amount": 150.00,
  "timestamp": "2026-02-12T10:00:00Z"
}
  • Clique em Send message

2.3 Enviar Mais Mensagens​

  • Envie mais 4 mensagens com conteúdos diferentes:

Mensagem 2:

{
  "orderId": "002",
  "customer": "Maria Santos",
  "amount": 250.00,
  "timestamp": "2026-02-12T10:01:00Z"
}

Mensagem 3:

{
  "orderId": "003",
  "customer": "Pedro Souza",
  "amount": 99.90,
  "timestamp": "2026-02-12T10:02:00Z"
}

Mensagem 4:

{
  "orderId": "004",
  "customer": "Ana Costa",
  "amount": 320.50,
  "timestamp": "2026-02-12T10:03:00Z"
}

Mensagem 5:

{
  "orderId": "005",
  "customer": "Carlos Lima",
  "amount": 180.00,
  "timestamp": "2026-02-12T10:04:00Z"
}

2.4 Verificar Estatísticas​

  • Volte para a página principal de Queues
  • Na listagem de filas, você verá as colunas:
    • Messages available: 5
    • Messages in flight: 0

Passo 3: Receber Mensagens​

3.1 Acessar Opção de Poll​

  • Clique novamente em Send and receive messages
  • Role até a seção Receive messages

3.2 Configurar Poll​

A interface já vem com configurações padrão:

  • Polling duration: 30 seconds
  • Maxium message count: 10

Opcional: Se quiser receber mensagens uma por vez para observar melhor, clique em Edit poll settings e altere:

  • Maximum message count: 1
  • Clique em Save

Caso contrário, mantenha o padrão (10) que funcione bem.

  • Clique em Poll for messages

3.3 Visualizar Mensagem Recebida​

A mensagem aparecerá na seção Messages abaixo

  • Clique no ID da mensagem para expandir e ver detalhes
  • Você verá 3 abas:
    • Aba Body: Conteúdo JSON que você enviou
    • Aba Attibutes: Mostra "No message attributes" (não enviamos atributos customizados)
    • Aba Details:
      • Message ID: ID único da mensagem (ex: 9c3683df-9c37-4570-a0d9-cbcef23aed03)
      • MD5 of message body: Hash do conteúdo
      • Sender account ID: ID da conta AWS que enviou
      • Message group ID: - (apenas filas FIFO)
      • Sent: Data e hora do envio
      • First received: Data e hora da primeira recepção
      • Size: Tamanho da mensagem em bytes (ex: 111 bytes)
      • Receive count: Quantas vezes a mensagem foi recebida (ex: 2)

3.4 Observar Ordem​

  • Faça poll várias vezes (clique em "Poll for messages" repetidas vezes)
  • Observe: As mensagens podem NÃO vir na ordem que você enviou
  • Exemplo: Você pode receber ordem 001 -> 003 -> 002 -> 004 -> 005

Best-Effort Ordering

Filas Standard fazem melhor esforço para manter ordem, mas não garantem. Mensagens podem chegar fora de ordem.

Passo 4: Testar Visibility Timeout​

4.1 Receber Mensagens Sem Deletar​

  • Faça poll para receber as mensagens
  • NÃO DELETAR as mensagens
  • Aguarde alguns segundos
  • Faça poll novamente

O que acontece:

  • Nos primeiros 30 segundos (visibility timeout), a mesma mensagem NÃO aparece novamente
  • Após 30 segundos, a mensagem volta a ficar disponível

4.2 Aguardar Expiração do Timeout​

  • Aguarde ~35 segundos
  • Faça poll novamente
  • A mesma mensagem deve aparecer novamente
Por Que Isso Acontece?

Se o consumidor não deletar a mensagem dentro do visibility timeout, o SQS assume que o processamento falhou e disponibiliza a mensagem novamente.

Passo 5: Deletar Mensagens​

5.1 Receber e Deletar​

  • Faça poll para receber uma mensagem
  • Após visualizar, clique no checkbox da mensagem
  • Clique em Delete (botão no topo)

5.2 Confirmar Deleção​

  • Confirme a deleção na janela popup
  • Mensagem é permanentemente removida da fila

5.3 Verificar Estatísticas​

  • Volte para página de detalhes
  • Mensagens available deve ter diminuído

Passo 6: Limpeza de Recursos​

6.1 Deletar Fila​

  • Na página de detalhes da fila
  • Clique em Delete (canto superior direito)
  • Digite o confirm
  • Clique em Delete
