Como criar um Client VPN Endpoint na AWS

🧭 Como criar um Client VPN Endpoint na AWS (passo a passo)​

Após gerar os certificados e importar o certificado do servidor no ACM, o próximo passo é criar o Client VPN Endpoint — que será o ponto de entrada para conexões remotas na sua VPC.

Este guia apresenta o processo completo usando o console da AWS, com explicações práticas para cada configuração.

🔍 1. Acesse o console da AWS​

  • No menu de busca, pesquise por client vpn endpoints e clique para abrir o serviço.

➕ 2. Clique em Create Client VPN Endpoint​

📝 3. Informações básicas​

Preencha os seguintes campos:

  • Name tag: vpn-bastion-endpoint (ou nome descritivo)
  • Description: Acesso remoto para VPC HostBastion
  • Client IPv4 CIDR: faixa de IPs que será atribuída aos dispositivos conectados (ex: 172.20.0.0/22)
    • Deve ter tamanho entre: /22 e /12
    • Não pode sobrepor com a CIDR de nenhuma VPC
    • Essa faixa será roteada até a VPC via túnel VPN

🔐 4. Autenticação​

  • Server certificate ARN: selecione o certificado do servidor (importado no ACM)
    • Este certificado foi gerado com a extensão serverAuth
  • Authentication options: escolha Mutual authentication
  • Client certificate ARN: selecione o certificado da CA que assinou o certificado do cliente
    • É com base nele que a AWS irá validar o client.crt

📄 5. Logging (opcional):​

Você pode ativar o envio de logs para o CloudWatch Logs, útil para auditoria e troubleshooting.

⚙️ 6. Configurações adicionais​

  • DNS server 1 \ DNS server 2 (opcional): defina IPs de servidores DNS customizados.

  • Transport Protocol: UDP (padrão e recomendado para VPN).

  • Split-tunnel: se ativado, apenas o tráfego destinado à VPC passará pela VPN (evita redirecionamento de todo o tráfego).

  • VPC ID: selecione a VPC onde o endpoint será criado.

  • Security Groups: define quais recursos os clientes poderão acessar após se conectar.

  • VPN Port: 443 (porta padrão da conexão VPN)

  • Enable self-service portal (opcional): portal web para que usuários baixem configurações (requer autenticação federada)

  • Session timeout hours: tempo máximo da sessão VPN (padrão: 24h)

  • Client Connect Handler (opcional): função Lambda executada quando um cliente se conecta

✅ 7. Criar o endpoint​

Após preencher todas as configurações, clique em Create Client VPN Endpoint.

O endpoint será criado com status Pending-association.

🌐 8. Associar uma subnet​

  1. Vá até a aba Target network associations
  2. Clique em Associate target network

  1. Selecione:
    • A VPC do endpoint
    • Uma subnet privada, que será o ponto de entrada do tráfego.

🛡️ 9. Criar regras de autorização​

As regras de autorização definem quais destinos os clientes conectados podem acessar dentro da VPC.

  1. Vá até a aba Authorization Rules
  2. Clique em Create authorization rule

  1. Configure os campos:
    • Destination network to enable access: coloque o CIDR da VPC (ex: 192.168.0.0/16)
    • Grant access to: Allow access to all users: (se estiver usando mutual auth com certificados)

🧪 10. Validação​

Após associar a subnet e criar as regras, o status do endpoint deve mudar para Available. A partir daí, você já poderá baixar o arquivo .ovpn, configurar seu cliente OpenVPN e testar a conexão.
