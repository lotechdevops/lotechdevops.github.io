Geração de certificados com OpenSSL para autenticação na VPN

Gerando certificados com OpenSSL para a AWS Client VPN​

Se você pretende configurar uma VPN Client VPN com autenticação mútua por certificados, é essencial que os certificados estejam corretamente gerados e assinados, com as extensões X.509 exigidas pela AWS.

Este guia mostra, de forma simples e direta, como gerar:

  • Uma autoridade certificadora (CA)
  • Um certificado de servidor com serverAuth
  • Um certificado para o cliente com clientAuth

Estrutura esperada ao final do processo​

vpn-certs/
├── ca.crt              # Certificado da CA
├── ca.key              # Chave privada da CA
├── server.key          # Chave do servidor
├── server.crt          # Certificado do servidor assinado pela CA
├── client.key          # Chave do cliente
├── client.crt          # Certificado do cliente assinado pela CA
├── server_openssl.cnf  # Extensões para o certificado do servidor
├── client_openssl.cnf  # Extensões para o certificado do cliente

Passo a passo​

1. Criar diretório de trabalho​

mkdir vpn-certs && cd vpn-certs

2. Gerar a Autoridade Certificadora (CA)​

openssl genrsa -out ca.key 2048

openssl req -x509 -new -nodes -key ca.key -sha256 -days 3650   -out ca.crt -subj "/CN=DevOpsR66VPN-CA"

3. Criar configuração para o certificado do servidor​

Crie o arquivo server_openssl.cnf com o seguinte conteúdo:

[ req ]
default_bits       = 2048
default_md         = sha256
distinguished_name = req_distinguished_name
req_extensions     = v3_req
prompt             = no

[ req_distinguished_name ]
CN = devopsr66.vpn.example.com

[ v3_req ]
basicConstraints = CA:FALSE
keyUsage = critical, digitalSignature, keyEncipherment
extendedKeyUsage = serverAuth

4. Gerar chave e CSR do servidor​

openssl genrsa -out server.key 2048

openssl req -new -key server.key -out server.csr -config server_openssl.cnf

5. Assinar certificado do servidor com a CA​

openssl x509 -req -in server.csr -CA ca.crt -CAkey ca.key   -CAcreateserial -out server.crt -days 3650 -sha256   -extfile server_openssl.cnf -extensions v3_req

6. Criar configuração para o certificado do cliente​

Crie o arquivo client_openssl.cnf com o seguinte conteúdo:

[ req ]
default_bits       = 2048
default_md         = sha256
distinguished_name = req_distinguished_name
req_extensions     = v3_req
prompt             = no

[ req_distinguished_name ]
CN = client1

[ v3_req ]
basicConstraints = CA:FALSE
keyUsage = critical, digitalSignature
extendedKeyUsage = clientAuth

7. Gerar chave e CSR do cliente​

openssl genrsa -out client.key 2048

openssl req -new -key client.key -out client.csr -config client_openssl.cnf

8. Assinar certificado do cliente com a CA​

openssl x509 -req -in client.csr -CA ca.crt -CAkey ca.key -CAcreateserial -out client.crt -days 3650 -sha256 -extfile client_openssl.cnf -extensions v3_req

Erros comuns que isso evita​

  • VERIFY KU ERROR: falta da extensão keyUsage
  • extendedKeyUsage missing: ausência de serverAuth ou clientAuth
  • ACM rejeita a importação do certificado do servidor

Próximo passo​

Com os certificados gerados, você pode:

  • Importar o certificado do servidor no AWS Certificate Manager (ACM)
  • Incluir o certificado do cliente no arquivo .ovpn usado para conectar via OpenVPN
