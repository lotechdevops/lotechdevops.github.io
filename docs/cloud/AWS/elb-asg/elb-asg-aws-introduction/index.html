Introdução ao Elastic Load Balancing (ELB) e Auto Scaling Groups (ASG) na AWS

Se você está começando sua jornada na AWS ou buscando entender melhor como criar aplicações resilientes e escaláveis na nuvem, dois serviços são absolutamente fundamentais: Elastic Load Balancing (ELB) e Auto Scaling Groups (ASG). Estes serviços trabalham em conjunto para garantir que suas aplicações sejam sempre disponíveis, performáticas e econômicas.

O que é Elastic Load Balancing (ELB)?​

O Elastic Load Balacing distribui automaticamente seu tráfego de entrada através de múltiplos alvos, como instâncias EC2, containers e endereços IP, em uma ou mais Zonas de Disponibildiade. Em termos simples, é como ter um controlador de tráfego inteligente que direciona visitantes do seu site para diferentes servidores, garantindo que nenhum servidor fique sobrecarregado.

Por que usar um Load Balancer?​

Imagine que você tem um e-commerce que recebe milhares de visitantes simultaneamente. Sem um load balancer, todos os usuários seriam direcinados para um único servidor, que rapidamente ficaria sobrecarregado e causaria lentidão ou até mesmo indisponibildiade do site.

Principais benefícios:​

  • Alta Disponibilidade: Se um servidor falhar, o tráfego é automaticamente redirecionado para servidores saudáveis.
  • Escalabilidade: Distribui a carga entre múltiplos servidores, permitindo atender mais usuários.
  • Flexibilidade: Permite adicionar ou remover servidores sem afetar o fluxo de requisições.
  • Health Checkes: Monitora constantemente a saúde dos servidores e só envia tráfego para os saudáveis.

Tipos de Load Balancers na AWS​

A AWS oferece quatro tipos de load balancers através do Elastic Load Balancing, cada um otimizado para cenários específicos:

1. Application Load Balancer (ALB)​

  • Camada: 7 (HTTP/HTTPS)
  • Ideal para: Aplicações web modernas, microserviços, containers.
  • Funcionalidades avançadas: Roteamento baseado em URL, suporte a WebSockets, integração com WAF.

2. Network Load Balancer (NLB)​

  • Camada: 4 (TCP/UDP)
  • Ideal para: Aplicações que precisam de ultra-alta performance e baixa latência.
  • Características: IPs estáticos, milhões de requisições por segundo.

3. Gateway Load Balancer (GLB)​

  • Camada: 3 (Network)
  • Ideal para: Implementação de appliances virtuais (firewalls, sistemas de detecção de intrusão).
  • Funcionalidade: Transparente para o tráfego de rede.

4. Classic Load Balancer (CLB)​

  • Status: Geração anterior (legado)
  • Recomendação: Migrar para ALB ou NLB.
  • Uso: Aplicações construídas na rede EC2-Classic.

O que são Auto Scaling Groups (ASG)?​

Amazon EC2 Auto Scaling ajuda você a garantir que tenha o número correto de instâncias Amazon EC2 disponíveis para lidar com a carga da sua aplicação.

Como funciona o ASG?​

Um Auto Scaling Group é uma coleção de instâncias EC2 que são tratadas como uma unidade lógica. Você define:

  • Capacidade Mínima: Número de instâncias sempre ativas.
  • Capacidade Desejada: Número ideal de instâncias em operação normal.
  • Capacidade Máxima: Número máximo de instância que podem ser criadas.

Principais Funcionalidades do ASG​

  • 1. Monitoramento de Saúde: Amazon EC2 Auto Scaling monitora automaticamente a saúde e disponibilidade das suas instâncias usando verificações de saúde do EC2 e substitui instâncias terminadas ou prejudicadas para manter sua capacidade desejada.

  • 2. Distribuição entre Zonas de Disponibilidade: O ASG distribui suas instâncias uniformemente entre múltiplas Zonas de Disponibildiade, proporcionando alta disponibilidade e resiliência.

  • 3. Múltiplos Tipos de Instâncias: Você pode usar diferentes tipos de instâncias (t3.micro, m5.large, etc) e opções de compra (On-Demand, Spot) no mesmo grupo.

  • 4. Integração com Load Balancer: Você pode usar load balancer do Elastic Load Balancing e verificações de saúde para garantir uma distribuição uniforme do tráfego da aplicação para suas intâncias saudáveis.

ELB + ASG: A Combinado Perfeita​

Quando você combina ELB com ASG, obtém uma arquitetura verdadeiramente resiliente e escalável:

Como trabalham juntos:​

  • 1. Registro Automático: Instâncias que são lançadas pelo seu Auto Scaling Group são automaticamente registradas com o load balancer.

  • 2. Desregistro Automático: Instâncias terminadas são automaticamente removidas do load balancer.

  • 3. Health Checks Compartilhados: O ASG pode usar as verificações de saúde do ELB para determinar se uma instância está saudável.

  • 4. Escalonamento Inteligante: O ASG pode escalar baseado em métricas do load balancer.

Arquitetura Típica:​

Internet → ELB → ASG (Instâncias EC2 em múltiplas AZs)
                 ↓
              Database/Storage
