Redirecionamento HTTP para HTTPS no Application Load Balancer

Agora que você já tem o listener HTTPS funcionando, vamos configurar o redirecionamento automático para garantir que todo tráfego use HTTPS. Isso é uma melhor prática essencial para segurança web moderna.

Por que implementar redirecionamento?​

🔒 Benefícios do redirecionamento automático:​

  • Segurança garantida: Usuários sempre usarão conexão criptografada.
  • Experiência uniforme: Não importa como o usuário digita a URL (http:// ou https://)
  • Compliance: Muitas regulamentações exigem tráfego criptografado.

🌐 Como funciona​

Usuário digita: http://exemplo.com
     ↓
ALB recebe na porta 80
     ↓
ALB responde: HTTP 301 (Redirect)
Location: https://exemplo.com
     ↓
Navegador faz nova requisição: https://exemplo.com
     ↓
ALB processa na porta 443 (HTTPS)

Códigos de redirecionamento​

  • HTTP 301: Redirecionamento permanente (recomendado).
  • HTTP 302: Redirecionamento temporário.
  • HTTP 307: Preserva método HTTP original.
  • HTTP 308: Redirecionamento permanente preservando método.

💡 Recomendação: Use HTTP 301 para redirecionamento HTTP → HTTPS.

Configuração​

Passo 1: Acessar as Rules do Listener HTTP​

Primeiro, vamos acessar as regras do listener HTTP (porta 80) que atualmente está encaminhando o tráfego para o target group.

Navegação na Console:​

  1. EC2 Console -> Load Balancers
  2. Selecione seu ALB
  3. Aba "Listeners"
  4. Encontre e selecione o listener HTTP:80
  5. Clique em "Manage Rules" -> "Edit rules"
  6. Selecione a "Rule" e clique em "Action" -> "Edit rule"

Passo 2: Configuração​

  1. Na opção de configuração "Default action", mude a opção "Forward to target groups" para "Redirect to URL"
  2. Deixe selecionado o protocol "HTTPS".
  3. Em "Port", digite a porta 443.
  4. Clique em "Save changes"
  5. Volte nas configurações do "ALB" e verifica se as opções do Listeners and Rules mudou.

📝 Explicação dos parâmetros​

  • Port: 443 - Porta padrão para HTTPS.
  • Host: {host} - Mantém o mesmo domínio.
  • Path: #{path} - Preserva o caminho da URL (/pagine/subpagina).
  • Query: {query} - Mantém parâmetros de query (?param=value).
  • Status code: HTTP 301 - Redirecionamento permanente.

Variáveis do ALB​

O ALB suporta essas variáveis para redirecionamento dinâmicos

  • #{host}- Domínio da requisição.
  • #{path} - Caminho da URL.
  • #{port} - Porta da requisição.
  • #{protocol} - Protocolo (HTTP/HTTPS).
  • #{query} - Query string.
  • #{uri} - URI completa.

Testes​

Agora vamos testar se o redirecionamento está funcionando corretamente.

Teste 1: Via Browser​

  1. Abra uma nova aba no navegador.
  2. Digite explicitamente: http://seu-dominio.com (sem HTTPS).
  3. Observe a barra de endereço: Deve mudar automaticamente para https://seu-dominio.com

Teste 2 : Via Linha de Comando​

curl -I http://webserver.devopsr66.com
