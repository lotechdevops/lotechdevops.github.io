Criando Launch Template para Auto Scaling Groups

Agora que você entende os conceitos fundamentais do ASG, vamos partir para a configuração prática. Neste capítulo, você aprenderá a criar um Template utilizado na criação de Auto Scaling Group.

Criar Launch Template​

O Launch Template é o "molde" que define como cada nova instância EC2 será criada pelo Auto Scaling Group. É aqui que configuramos a AMI, tipo de instância, security groups e o script que automatiza a configuração inicial.

Passo 1: Acessar Launch Templates​

  1. AWS Console → EC2 → Instances → Launch Templates
  2. Clique em "Create launch template"

Passo 2: Configurações Básicas do Template​

  1. Launch template name: Digite um nome para o seu template.
  2. Template version description: Digite uma descrição da versão do template.
  3. Auto Scaling guidance: ✅ Marque esta opção
  • Otimiza configurações para uso com ASG
  • Habilita recursos específicos do Auto Scaling

Passo 3: Application and OS Images (AMI)​

Quick Start (Recomendado):

  1. Selecione uma AMI base: Ex: Amazon Linux 2023 AMI
  2. Selecione o tipo de instância: Ex: t2.micro
  3. Selecione uma key pair para acesso SSH (Caso necessário)

Passo 4: Network Settings​

  1. Subnet: Não especifique (será configurado no ASG)
  2. Security groups: Selecione o security group das instâncias
    • Deve permitir:
      • HTTP (80) do Security Group do ALB
      • HTTPS (443) do Security Group do ALB (se necessário)
      • SSH (22) do seu IP (opcional)

Passo 5: Storage​

  1. Volume padrão: 8GB (gp3)
  2. Volumes adicionais: Clique em "Add new volume" se necessário

Passo 6: Resource Tags (Opcional)​

Configure tags para organização:

  • Billing: Rastreamento de custos por projeto
  • Automation: Scripts podem filtrar por tags
  • Compliance: Identificação de recursos

Passo 7: User Data Script​

  1. Navegue até: "Advanced details"
  2. Encontre: "User data"
  3. Cole o script de configuração das instâncias

Passo 8: Finalizar​

  1. Review todas as configurações
  2. Clique em "Create launch template"
