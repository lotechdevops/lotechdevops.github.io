Static Website Hosting no Amazon S3

Introdução​

Além de ser um serviço de armazenamento de objetos, o Amazon S3 pode ser usado para hospedar sites estáticos de forma simples, barata e altamente escalável. Essa funcionalidade é ideal para páginas HTML, CSS e JavaScript, que não dependem de processamento dinâmico no servidor. Com alguns cliques, é possível transformar um buket em um servidor de site disponível globalmente.

O que é um Site Estático?​

Um site estático é composto por arquivos fixos, normalmente HTML, CSS, imagens e JavaScript. Diferente de aplicações dinâmicas (que usam banco de dados e linguagens como PHP, Python ou Node.js), os sites estáticos servem sempre os mesmo arquivos para qualquer usuário.

Esse modelo é perfeito para portofólios, blogs, landing pages, documentações e qualquer conteúdo que não exija backend.

Como Funciona no S3​

Quando você ativa o recurso Static Website Hosting em um bucket, o S3 passa a se comportar como um servidor web:

  • O bucket precisa ter o mesmo nome do domínio se você deseja integrar com DNS (exemplo: meusite.com).
  • Você define um index document (ex: index.html) e um error document (ex: error.html).
  • O conteúdo passa a ser acessível via um endpoint público do S3 (ex: http://meu-bucket.s3-website-us-east-1.amazonaws.com).

Integração com Domínio (Opcional)​

Se você possui um dominio (ex: registrado no Route 53):

  1. Crie um record CNAME ou Alias apontando para o endpoint do bucket.
  2. Para melhor performance e HTTPS, utilize o Amazon CloudFront como CDN na frente do bucket.

Custos​

  • Armazenamento no S3: Cobrado por GB/mês.
  • Requests (GET) Cobrados por quantidade de acessos.
  • Transferência de dados: Cobrança padrão da AWS, mas com custo muito baixo para pequenos sites.
