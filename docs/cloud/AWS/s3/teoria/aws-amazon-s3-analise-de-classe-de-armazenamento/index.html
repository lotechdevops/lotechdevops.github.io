Storage Class Analysis

Introdução​

Aplicar Lifecycle Rules de forma eficiente depende de saber quando os objetos deixam de ser acessados com frequência. Mas como tomar essa decisão sem mover arquivos de forma prematura ou gastar mais do que o necessário?

É para isso que existe o Amazon S3 Analytics - Storage Class Analysis, um recurso que coleta estatísticas sobre padrões de acesso aos objetos e ajuda a planejar transições para classe de armazenamento mais econômicas.

O que é o Storage Class Analysis?​

O Storage Class Analysis é um recurso da Amazon S3 que analisa estatísticas de uso dos objetos armazenados e mostra quando eles podem ser candidatos a transição para classes mais econômicas, como Standard-IA.

  • Os relatórios são atualizados diariamente.
  • Demora cerca de 24 a 48 horas para começar a exibir os primeiros dados após habilitar a análise.
  • Ele fornece recomendações específicas para transições entre Standard e Standard-IA, que são as classes mais comuns no dia a dia.
  • Importante: ele não funciona com One Zone-IA nem com as classes Glacier.

Essa análise não move os dados automaticamente, ela serve como base para decisões de Lifecycle Rules.

Como Funciona​

  1. Você habilita o Storage Class Analysis em um bucket ou em um prefixo específico.
  2. O S3 começa a coletar métricas de leitura e gravação dos objetos.
  3. Relatórios em formato CSV são gerados em um bucket designado, atualizados diariamente.
  4. Esses relatórios podem ser analisados diretamente no Console, com Athena, ou integrados a ferramentas externas de BI.

Esse processo é o primeiro passo recomendado antes de criar Lifecycle Rules, pois evita decisões baseadas apenas em suposições.

Casos de Uso Comuns​

  • Identificar objetos que já não são acessados com frequência e podem ser movidos para Standard-IA.
  • Justificar a aplicação de regras de ciclo de vida com base em dados reais.
  • Melhorar políticas existentes de Lifecycle Rules, ajustando prazos de transição com base no uso.

Exemplo prático​

Suponha que você armazene logs de aplicação em um bucket S3.

  • Nos primeiros 30 dias, eles são acessados com frequência.
  • Depois de 60 dias, o uso cai drasticamente.

Com o Storage Class Analysis, você percebe esse padrão no relatório e cria uma Lifecycle Rule para mover logs com mais de 60 dias para Standard-IA, economizando até 40% em custos.

Conclusão​

O Amazon S3 Storage Class Analysis é um aliado essencial para otimização de custos no S3. Ele não move dados automaticamente, mas fornece relatórios confiáveis para embasar a criação ou melhoria de Lifecycle Rules.

É o primeiro passo recomendado para qualquer estratégia de gestão de ciclo de vida dos objetos, garantindo que a transição entre classes seja feita com segurança e eficiência.
