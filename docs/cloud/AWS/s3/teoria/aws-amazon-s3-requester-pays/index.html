Amazon S3 – Requester Pays

Introdução​

Por padrão, o dono de um bucket no Amazon S3 é responsável por pagar todos os custos de armazenamento, requisições e transferência de dados. Mas e se você quiser compartilhar um grande conjunto de dados com outras contas, sem assumir o custo de cada download feito por terceiros?

Para isso, existe a funcionalidade Requester Pays, que transfere parte dos custos para quem solicita os dados.

Como Funciona​

  • Modo Padrão (Standard Bucket): o dono do bucket paga tanto pelo armazenamento quanto pelo tráfego de saída (download) gerado pelos usuários.
  • Modo Requester Pays: o dono do bucket continua pagando pelo armazenamento, mas os custos de requisição e download são pagos pelo requester (quem faz a solicitação).

Regras de Características​

  • Em geral, o o dono do bucket paga todos os custos de um bucket normal.
  • Com Requester Pays habilitado, o requester paga pelo request e pelo download dos dados.
  • Esse modelo é útil para compartilhar grandes datasets entre contas, sem que o dono assuma todos os custos de transferência.
  • O requester deve estar autenticado na AWS para usar essa funcionalidade, acessos anônimos não são suportados.

Casos de Uso​

  • Compartilhamento de dados públicos científicos ou governamentais: organizações podem publicar grandes datasets no S3 sem arcar com os custos de milhares de downloads.
  • Colaboração entre empresas: quando múltipas contas AWS precisam acessar o mesmo repositório de dados, cada um paga pelo seu uso.
  • Projetos acadêmicos ou de pesquisa: universidades ou centros de dados podem expor informações, mas quem consome arca com o custo do tráfego.
