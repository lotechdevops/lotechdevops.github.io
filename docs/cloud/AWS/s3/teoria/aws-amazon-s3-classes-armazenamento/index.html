Classes de Armazenamento no Amazon S3

Introdução​

Armazenar dados na nuvem é como organizar roupas em um guarda-roupas: algumas peças você usa todos os dias, outras ficam guardadas para ocasiões especiais, e algumas você só guarda "para o futuro". No Amazon S3, essa lógica é representada pelas Classes de Armazenamento, que permitem equilibrar custo x performance conforme a frequência e a forma como seus dados são acessados.

O que são Classes de Armazenamento​

As classes de armazenamento do S3 são "categorias" que você pode escolher ao salvar seus objetos. Cada classe tem um preço, durabilidade e disponibilidade diferentes, otimizados para cenários específicos. Assim, você não paga o mesmo valor para armazenar um dado crítico e acessado diariamente, e para guardar um backup que só será usado em caso de emergência.

Principais Classes de Armazenamento​

S3 Standard​

A classe S3 Standard é a mais utilizada dentro do Amazon S3 e foi projetada para dados acessados com frequência. Ela garante alta durabilidade, disponibilidade e baixa latência, sendo ideal para aplicações críticas, sites estáticos, conteúdos de streaming ou qualquer tipo de dado que precise estar disponível a qualquer momento. Por armazenar cópias dos objetos em múltiplas zonas de disponibildiade, o S3 Standard oferece resiliência contra falhas, embora seja também uma das opções mais caras em termos de custo de gigabyte.

S3 Standard-IA (Infrequent Access)​

A classe S3 Standard-IA (Infrequent Access) é indicada para dados que não são acessados com frequência, mas que ainda precisam estar disponíveis de forma imediata quando requisitados. Essa classe oferece a mesma durabilidade do S3 Standard, porém com custo de armazenamento menor e uma taxa adicional por recuperação de dados. É bastante utilizada para backups, relatórios e informações que ficam armazenadas por longos períodos, mas que ainda exigem recuperação rápida em cado de necessidade.

S3 One Zone-IA​

Já a classe S3 One Zone-IA é semelhante ao Standard-IA, mas com uma diferença importante: os dados são armazenados em apenas uma zona de disponibilidade. Isso reduz significativamente o custo de armazenamento, mas também diminui a resiliência, já que em caso de falha na zona escolhida os dados podem ser perdidos. Essa classe é recomendada para dados secundários, cópias de backup ou informações que podem ser recriadas facilmente.

S3 Intelligent-Tiering​

A classe S3 Intelligent-Tiering é voltada para dados cujo padrão de acesso é imprevisível. Nesse modelo, o próprio S3 analisa o comportamento de uso dos objetos e os movimenta automaticamente entre camadas de acesso frequente e infrequente. Essa automação permite otimizar custos sem comprometer a performance, eliminando a necessidade de o administrador decidir manualmente em qual classe armazenar cada dado. É ideal para workloads dinâmicos, onde não há clareza sobre quando os dados serão acessados.

S3 Glacier Instant Retrieval​

A classe S3 Glacier Instant Retrieval foi projetado para arquivamento de dados que não são acessados com frequência, mas que precisam estar disponíveis de forma quase imediata quando soliticados. A recuperação acontece em milissegundos, o que o torna adequado para dados de compliance ou documentos que precisam ser preservados a longo prazo, mas que eventualmente podem ser consultados rapidamente.

S3 Glacier Flexible Retrieval​

A classe S3 Glacier Flexible Retrieval, anteriormente chamada apenas de "Glacier", oferece custos ainda mais reduzidos para arquivamento, mas com tempos de recuperação que variam de minutos a horas, dependendo do modo escolhido. Essa classe é bastante usada para armazenamento de longo prazo de dados que raramente são acessados, como backups antigos ou informações arquivadas que não exigem disponibilidade imediata.

S3 Glacier Deep Archive​

Por fim, a classe S3 Glacier Deep Archive é a opção mais econômica do Amazon S3, sendo destinada a arquivamento de dados de longo prazo, como registros históricos ou informações legais que precisam ser mantidas por 7 a 10 anos. Nesse caso, os prazos de recuperação podem chegar a 12 horas, o que a torna adequada apenas para dados que dificilmente serão acessados, mas que precisam estar guardados com segurança.

Como Escolher a Classe Correta?​

A decisão depende de três perguntas principais:

1. Com que frequência os dados serão acessados?

  • Uso diário -> S3 Standard
  • Acesso eventual -> S3 Standard-IA ou Intelligent-Tiering

2. Qual a criticidade dos dados?

  • Críticos, que não podem ser perdidos -> S3 Standard (replicado em múltiplas AZs)
  • Toleram perda de uma AZ -> S3 One Zone-IA

3. Qual o tempo aceitável para recuperação?

  • Instantâneo -> Standard / Glacier Instant Retrieval
  • Minutos a horas -> Glacier Flexible Retrieval
  • Até 12 horas -> Glacier Deep Archive

Casos de Uso Comuns​

  • S3 Standard -> sites estáticos, imagens de aplicativos, logs ativos.
  • S3 Standard-IA -> backups mensais, dados de relatórios.
  • S3 One Zone-IA -> cópias secundárias de backup, dados reprocessáveis.
  • S3 Intelligent-Tiering -> aplicações com dados de uso imprevisível.
  • S3 Glacier -> arquivos de auditoria, dados de compliance, gravações antigas.
  • S3 Glacier Deep Archive -> retenção legal de dados por 7 a 10 anos.

Preços de Armazenamento por Classe​

S3 Standard​

A camada S3 Standard tem preço em faixas: nos EUA (us-east-1), os primeiros 50 TB são cobrados a aproximadamente US$ 0,023 por GB/mês, a faixa seguinte (até 500 TB) custa US$ 0,022 por GB/mês, e acima de 500 TB, o valor cai para US$ 0,021 por GB/mês. Essas tarifas são típicas da região N.Virginia, consideradas referência para estimativas globais.

S3 Standard-IA​

Na camada S3 Standard-IA, o custo de armazenamento fica em torno de US$ 0,0125 por GB/mês, com cobrança adicional para cada acesso realizado aos dados.

S3 One Zone-IA​

A classe S3 One Zone-IA, que armazena dados em apenas uma zona de disponibilidade, é mais econômica, cerca de US$ 0,01 por GB/mês, ou seja, aproximadamente 20% mais barato que a versão Standard-IA.

S3 Intelligent-Tiering​

A S3 Intelligent-Tiering adapta automaticamente os objetos entre níveis de acesso frequente e infrequente, conforme o uso. O valor varia de acordo com a camada ativa de armazenamento (por exemplo, pode ser cobrado como Standard ou Glacier Deep Archive), e há uma taxa de monitoramento de aproximadamente US$ 0,0025 por 1.000 objetos/mês.

S3 Glacier Instant Retrieval​

A classe S3 Glacier Instant Retrieval, voltada para arquivamento com acesso em milissegundos, tem um custo de armazenamento inicial de US$ 0,004 por GB/mês. Essa tarifa representa uma economia de até 68% em relação à Standard-IA.

S3 Glacier Flexible Retrieval​

Já a S3 Glacier Flexible Retrieval oferece armazenamento ainda mais barato, aproximadamente US$ 0,0036 por GB/mês.

S3 Glacier Deep Archive​

Por fim, a opção mais econômica é o S3 Glacier Deep Archive, com armazenamento a partir de apenas US$ 0,00099 por GB/mês, cerca de US$ 1 por TB/mês.
