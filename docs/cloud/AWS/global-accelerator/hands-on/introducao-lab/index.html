Introdução ao Lab

Objetivo do Lab​

Neste laboratório você vai criar um AWS Global Accelerator, configurar endpoints em duas regiões AWS diferentes, testar a conectividade e verificar o failover automático.

O que você vai aprender:

  • Criar instâncias EC2 em múltiplas regiões
  • Configurar Application Load Balancers
  • Criar e configurar Global Accelerator
  • Adicionar Listerners e endpoints groups
  • Testar IPs Anycast e distribuição de tráfego
  • Verificar failover automático

Tempo estimado: 45-60 minutos

Arquitetura Final​

Global Accelerator (2 IPs Anycast)
    ↓
Listener (porta 80, TCP)
    ↓
├── Endpoint Group us-east-1 (70%)
│   └── Application Load Balancer
│       └── EC2 (servidor web simples)
│
└── Endpoint Group us-west-2 (30%)
    └── Application Load Balancer
        └── EC2 (servidor web simples)

Fluxo do Trafego:

  1. Usuário acessa IP Anycast (ex: 75.2.60.5)
  2. Tráfego roteado para edge location AWS mais próxima
  3. Viaja pela rede AWS backbone até região de destino
  4. 70% vai us-east-1, 30% para us-west-2 (baseado em Traffic Dial)
  5. ALB distribui para instância EC2
  6. Página web identifica qual região atendeu

Pré-requisitos​

  • Conta AWS ativa
  • Permissões para criar:
    • EC2 instances
    • Application Load Balancers
    • Global Accelerator
    • Security Groups
