Criar Instâncias EC2

Vamos criar duas instâncias EC2 com servidores web Apache em regiões diferentes. Cada instância mostrará uma página identificando sua região.

Passo 1: Criar EC2 em us-east-1​

1.1 Acessar Console EC2​

  • Acesse o console EC2 e certifique-se que está na região us-east-1.
  • Clique em Launch instances

1.2 Configurar Instância​

  • Name: global-accelerator-lab-us-east
  • AMI: Amazon Linux 2023
  • Instance type: t2.micro
  • Key pair: Selecione uma existente ou crie nova

1.3 Configurar Network Settings​

  • Clique em Edit na seção Network settings
  • Em VPC, selecione Default VPC
  • Em Subnet, selecione qualquer subnet pública
  • Em Auto-assign public IP, deixa selecionado a opção Enable
  • Nas configurações do Security Group, clique em Create security group e preenche os campos:
    • Security group name: global-accelerator-lab-sg-us-east
    • Description: Security group for Global Accelerator lab
    • Adicione as regras HTTP:
      • Type: HTTP
      • Port: 80
      • Source type: Anywhere
      • Source: 0.0.0.0/0
    • Adicione outra regra IPv6:
      • Type: HTTP
      • Port: 80
      • Source type: Anywhere
      • Source: ::/0

1.4 Adicionar User Data​

  • Role a página até Advanced details.
  • Expanda a seção.
  • Role até o final até encontrar User Data
  • Cole o script abaixo no campo em branco
#!/bin/bash
yum update -y
yum install -y httpd
systemctl start httpd
systemctl enable httpd
echo "<h1 style='text-align:center; color:#667eea; margin-top:50px;'>US-EAST-1 (N. Virginia)</h1>" > /var/www/html/index.html

1.5 Lançar Instância​

  • Clique em Launch instance no canto inferior direito.
  • Aguarde a confirmação.

1.6 Aguardar Inicialização​

  • Vá em Instances no menu lateral
  • Aguarde até:
    • Instance state: Running
    • Status check: 2/2 checks passed

1.7 Testar Servidor Web​

  • Selecione a instância global-accelerator-lab-us-east.
  • Copie o Public IPv4 DNS
  • Abra uma nova aba no navegador e acesse:
http://ec2-xx-xxx-xxx-xxx.compute-1.amazonaws.com
  • Você deve ver a página identificando US-EAST-1

Passo 2: Criar EC2 em us-west-2​

2.1 Mudar Região​

  • No canto superior direito do console AWS, mude para região us-west-2

2.2 Repetir Processo​

  • Repita EXATAMENTE os mesmos passos do Passo 1, com estas diferenças:
    • Name: global-accelerator-lab-us-west
    • Security group name: global-accelerator-lab-sg-us-west
    • User data: Use o mesmo script, mas mude:
      • <h1 style='text-align:center; color:#667eea; margin-top:50px;'>US-WEST-2 (Oregon)</h1>

2.3 Testar Servidor Web​

  • Após inicialização, teste acessando o Public DNS da instância us-west-2.
  • Deve mostrar US-WEST-2.

Verificação​

Você deve ter agora:

  • 2 instâncias EC2 (1 em us-east-1, 1 em us-west-2)
  • Ambas com status "Running"
  • Ambas com servidor Apache funcionando
  • Ambas acessíveis via HTTP
  • Cada uma mostrando sua região na página
