Testar o Global Accelerator

Agora vamos testar o Global Accelerator acessando DNS name e verificando como o tráfego é distribuído entre as regiões.

Passo 1: Acessar via DNS do Global Accelerator​

1.1 Copiar DNS Name​

  • Na página de detalhes do Global Accelerator, localize o DNS name
  • Será algo como: a185e60262651ea82.awsglobalaccelerator.com
  • Copie o DNS name

1.2 Testar Acesso​

  • Abra uma nova aba no navegador
  • Digite na barra de endereço: http://a185e60262651ea82.awsglobalaccelerator.com/

Você verá a página mostrando US-EAST-1 ou US-WEST-2 dependendo de qual região atendeu sua requisição.

DNS vs IPs Anycast

O DNS name resolve para os 2 IPs Anycast que você recebeu. É mais fácil usar o DNS (não precisa decorar IPs), mas ambas as formas funcionam igual.

Passo 2: Testar Distribuição de Tráfego​

2.1 Recarregar Página Múltiplas Vezes​

Como configuramos:

  • us-east-1: 70% do tráfego
  • us-west-2: 30% do tráfego
  • Com a página aberta no DNS do Global Accelerator, recarregue várias vezes rapidamente
  • Pressione Ctrl+R múltiplas vezes
  • Observe qual região aparece em cada requisição
Por Que Alterna Entre Regiões?

Como não configuramos Client Affinity, cada requisição é distribuída independentemente baseada no Traffic Dial (70% para us-east-1, 30% para us-west-2).

Se tivéssemos configurado Client Affinity como "Source IP", todas as requisições do mesmo IP de origem iriam sempre para a mesma região.

Por Que É Mais Rápido?

O Global Accelerator roteia seu tráfego pela rede privada AWS backbone em vez da internet pública. A requisição:

  1. Entra na edge location AWS mais próxima de você
  2. Viaja pela rede otimizada da AWS (sem congestionamento)
  3. Chega na região de destino
