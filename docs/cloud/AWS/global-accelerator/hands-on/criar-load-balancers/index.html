Criar Application Load Balancers

Agora vamos criar Application Load Balancers (ALBs) em cada região para distribuir tráfego para as instâncias EC2. Os ALBs serão os endpoints do Global Accelerator.

Passo 1: Criar ALB em us-east-1​

1.1 Acessar Load Balancers​

  • Certifique-se que está na região us-east-1.
  • No console EC2, vá em Load Balancers no menu lateral esquerdo (seção Load Balancing).
  • Clique em Create load balancer.

1.2 Selecionar Tipo​

  • Selecione Application Load Balancer e clique em Create

1.3 Configurar Informações Básicas​

  • Load balancer name: ga-lab-alb-us-east
  • Scheme: Internet-facing
  • IP address type: IPv4

1.4 Configurar Network Mapping​

  • VPC: Selecione a Default VPC
  • Mapping: Selecione pelo menos 2 Availability Zones:
    • us-east-1a
    • us-east-1e

1.5 Configurar Security Groups​

  • Na seção Security groups, remova o security group padrão (clique no "X")
  • Clique em Select security group e selecione: global-accelerator-lab-sg-us-east

1.6 Criar Target Group​

  • Na seção Listeners and routing, você verá:
    • Protocol: HTTP
    • Port: 80
    • Default action: Forward to target groups
  • Clique em create target group (abrirá nova aba).

1.7 Configurar Target Group​

  • Mantenha o target type como: Instance
  • Target group name: ga-lab-tg-us-east
  • Protocol: HTTP
  • Port: 80
  • VPC: Default VPC
  • Protocol version: HTTP1

Health checks:

  • Health check protocol: HTTP
  • Health check path: /
  • Em Advanced health check settings mantenha as configurações padrões:
    • Health threshold: 5
    • Unhealthy threshold: 2
    • Timout: 5 seconds
    • Interval: 30 seconds
  • Clique em Next no final da página.

1.8 Registrar Target (Instância EC2)​

  • Na lista Available instance, selecione a instância `global-accelerator-lab-us-east.
  • Ports: 80 (já selecionado)
  • Clique no botão Include as pending below.
  • A instância deve aparecer na seção Targets abaixo.
  • Clique em Next
  • Revise as configurações e clique em Create target group
  • Feche esta aba e volte para a aba do Load Balancer.

1.9 Selecionar Target Group no ALB​

De volta na aba do Load Balancer:

  • Na seção Listeners and routing, clique no ícone de refresh (🔄)
  • Selecione o target group: ga-lab-tg-us-east

1.10 Criar Load Balancer​

  • Role até o final da página.
  • Revise as configurações.
  • Clique em Create load balancer.

1.11 Testar ALB​

  • Selecione o load balancer ga-lab-alb-us-east
  • Copie o DNS name
  • Abra uma nova aba no navegador e acesse: ga-lab-alb-us-east-1615700670.us-east-1.elb.amazonaws.com
  • Você deve ver a página mostrando US-EAST-1

Dica

Se receber erro 503 ou 504, aguarde mais 1-2 minutos. O ALB precisa que o health check da instância passe antes de enviar tráfego.

Passo 2: Criar ALB em us-west-2​

2.1 Mudar Região​

  • Mude para região us-west-2 no canto superior direito.

2.2 Repetir Processo​

  • Repita TODOS os passos do Passo 1, com estas diferenças:

  • Load balancer name: ga-lab-alb-us-west

  • VPC: Default VPC (us-west-2)

  • Availability Zones: Selecione 2 AZs de us-west-2:

    • us-west-2a
    • us-west-2e

  • Security group: global-accelerator-lab-sg-us-west

  • Target group name: ga-lab-tg-us-west

  • Target: ga-lab-tg-us-west

2.3 Aguardar e Testar​

  • Aguarde status Active.
  • Teste o DNS do ALB - deve mostrar US-WEST-2.

Verificação​

Você deve ter agora:

  • 2 Application Load Balancers (1 em us-east-1, 1 em us-west-2)
  • Ambos com status "Active"
  • 2 Target Groups criados
  • Targets com status "Healthy"
  • Ambos ALBs acessíveis via DNS e mostrando página correta

Recursos criados até agora:

RecursoRegiãoStatus
EC2 us-eastus-east-1✅ Running
EC2 us-westus-west-2✅ Running
ALB us-eastus-east-1✅ Active
ALB us-westus-west-2✅ Active
Target Group us-eastus-east-1✅ Healthy
Target Group us-westus-west-2✅ Healthy
