Preços, Monitoramento e Segurança

Modelo de Preços​

O Global Accelerator cobra por duas métricas principais:

Taxa Fixa por Accelerator​

$0.025 USD por hora por accelerator ativo (~$18/mês ou ~R$ 100/mês)

Importante:

  • Cobrado enquanto o accelerator existir, mesmo sem tráfego.
  • Se você criar e esquecer ligado, paga ~R$ 100/mês fazendo nada.
  • Não há free tier para essa taxa fixa.
  • Cotação aproximada: $1.00 USD = R$ 5,50 (varia diaramente)

Exemplo de custo:

1 accelerator ativo por 1 mês = 720 horas × R$ 0.025 = R$ 18
- USD: 720 horas x $0.025 = $18 USD
- BRL: $18 x 5.50 = ~R$ 99/mês 

2 accelerators ativos = R$ 36/mês
- USD: $36/mês
- BRL: ~R$ 198/mês

Transferência de Dados​

Varia por região de origem e destino do tráfego, similar aos preços do CloudFront.

Exemplos de preços (aproximados):

  • América do Norte, Europa: ~$0.015 USD - $0.020 USD por GB
  • Ásia-Pacífico: ~$0.025 USD - $0.09 USD por GB
  • América do Sul: ~$0.05 USD - $0.09 USD por GB

Monitoramento e Métricas​

CloudWatch Métricas​

O Global Accelerator integra nativamente com Amazon CloudWatch para monitoramento.

Métricas principais disponíveis:

ProcessedBytesIn:

  • Volume de dados recebidos pelo accelerator (bytes de entrada)
  • Útil para: Medir tráfego de usuários, calcular custos de transferência

ProcessedBytesOut:

  • Volume de dados enviados pelo accelerator para usuários (bytes de saída)
  • Útil para: Monitorar tráfego de resposta, identificar picos

NewFlowCount:

  • Número de novas conexões TCP/UDP estabelecidas
  • Útil para: Identificar picos de tráfego, dimensionar endpoints

ActiveFlowCount:

  • Número de conexões TCP/UDP ativas no momento
  • Útil para: Monitorar carga atual, detectar anomalias

ClientConnections:

  • Total de conexões de clientes ao accelerator
  • Útil para: Entender volume de usuários simultâneos

Dimensões de Métricas​

As métricas podem ser filtradas por:

  • Accelerator: Ver métricas de um accelerator específico.
  • Listener: Métricas por listener (porta/protocolo).
  • EndpointGroup: Métricas por região.
  • Endpoint: Métricas de endpoints individuais.

Exemplo de uso:

Ver ActiveFlowCount filtrado por:
- Accelerator: meu-acelerador-gaming
- EndpointGroup: us-east-1
→ Mostra conexões ativas apenas na região US

Alarmes CloudWatch​

Configure alarmes para ser notificado sobre problemas:

Alarmes recomendados:

Alta Latência:

Se latência média > 100ms por 5 minutos
→ Notificar equipe via SNS

Queda de Tráfego:

Se NewFlowCount < threshold por 10 minutos
→ Pode indicar problema no accelerator ou DNS

Endpoints Unhealthy:

Se todos endpoints de uma região ficam unhealthy
→ Alerta crítico imediato

Flow Logs​

O Global Accelerator oferece Flow Logs para análise detalhada de tráfego.

Informações capturadas:

  • IP de origem do cliente
  • IP de destino
  • Porta de origem e destino
  • Protocolo (UDP/TCP)
  • Número de bytes transferidos
  • Timestamp

Destinos suportados:

  • Amazon S3
  • CloudWatch Logs

Segurança e Compliance​

AWS Shield Standard​

Incluído automaticamente sem custo adicional.

Protege contra ataque DDoS mais comuns (camadas 3 e 4):

  • SYN floods
  • UDP reflection attacks
  • Outros ataques volumétricos

Benefício da arquitetura Anycast: Ataques DDoS são distribuídos entre centenas de edge locations, diluindo o impacto.

AWS Shield Advanced​

Custo: ~3.000/mês USD + fess adicionais

Oferece:

  • Proteção contra ataques DDoS mais sofisticados
  • Equipe de resposta a DDoS 24/7
  • Proteção financeira contra custos de DDoS
  • Visibilidade avançada de ataques

Quando vale a pena: Aplicações críticas que não podem ter downtime e são alvos frequentes de ataques.

Integração com AWS WAF​

Global Accelerator NÃO suporta AWS WAF diretamente (diferente do CloudFront)

Solução: Aplicar WAF nos endpoints (Application Load Balancer), não no accelerator.

Global Accelerator → ALB (com WAF) → EC2
                      ↑
                   WAF aqui
Lembre-se

Global Accelerator tem custo fixo mensal mesmo sem tráfego. Sempre desabilite/delete accelerators não utilizados para evitar custos desnecessários.
