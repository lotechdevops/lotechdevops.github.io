Criação de Grupos de Posicionamento (Placement Group)

O objetivo deste tutorial é ensinar, de forma prática e detalhada, como criar e configurar um Placement Group no Amazon EC2, entendendo os diferentes tipos disponíveis (Clusterm Spread e Partition) e como lançar instâncias dentro dele.

Tipos de Placement Group​

Antes do passo a passo, é importante lembrar o três tipos:

  1. Cluster: Coloca as instâncias próximas no mesmo rack físico para alta performance e baixa latência.
  2. Spread: Distribui instâncias em diferentes racks físicos, melhorando tolerância a falhas.
  3. Partition: Divide instâncias em partições lógicas, cada uma com racks separados.

Tutorial​

1. Criar o Placement Group​

  1. Abra o console do Amazon EC2: https://console.aws.amazon.com/ec2/
  2. No painel de navegação, escolha Rede e Segurança e depois Placement groups
  3. Clique em Criar grupo de posicionamento
  4. Especifique um nome para o grupo
  5. Escolha a estratégia de posicionamento para o grupo: Cluster, Distribuído ou Partição.
    • Se escolher Distribuído, você deverá escolher o nível de distribuição: Rack ou Host.
    • Se escolher Partição, você deverá inserir o número de partições para o grupo.
  6. (Opcional) Para adicionar uma tag, escolha Adicionar nova tag e insira a chave e valor.
  7. Clique em Criar grupo

2. Adicionar instâncias ao Grupo de Posicionamento​

  1. Abra o console do Amazon EC2: https://console.aws.amazon.com/ec2/
  2. No painel de navegação, clique em Instâncias
  3. Durante a criação da Instância, vá até Detalhes avançados e procure pela opção Grupo de posicionamento
  4. Selecione um grupo de posicionamento existente
    • Caso o tipo seja Partição, selecione o número da partição de destino
  5. Clique em Executar instância
