Criação de Endereços IP Elástico (Elastic IP)

O objetivo deste tutorial é ensinar, de forma clara e prática, como criar (alocar), associar, transferir e desassociar um endereço Elastic IP a recursos da AWS, como instâncias EC2 ou interfaces de rede.

1. Alocar um endereço IP elástico​

  1. Abra o console do Amazon EC2 em https://console.aws.amazon.com/ec2/
  2. No painel de navegação, escolha Rede e Segurança e depois IPs elásticos
  3. Escolha Alocar endereço IP elástico
  4. Em Conjunto de endereços IPv4 público, selecione as seguinte opções:
    • Conjunto de endereços IPv4 da Amazon - Usado na maioria dos casos
    • As demais opções só estarão disponíveis caso o cliente traga o próprio endereço IP para a conta da AWS.
  5. Escolha o Grupo de borda de rede onde o EIP será alocado.

Em alguns casos, o grupo de borda será predefinido e não poderá ser alterado. Isso significa que o EIP será anunciado em todas as zonas de disponibilidade (AZs) da região selecionada.

  1. (Opcional) Para adicionar uma tag, escolha Adicionar nova tag e insira uma chave e uma valor de tag.
  2. Clique Alocar, após Alocar o IP ficará disponível para realizar a associação.

2. Associar um endereço IP elástico em uma Instância EC2​

  1. Abra o console do Amazon EC2 em https://console.aws.amazon.com/ec2/
  2. No painel de navegação, escolha Rede e Segurança e depois IPs elásticos
  3. Selecione o endereço IP elástico que deseja associar.
  4. Clique em Ações -> Associar endereço IP elástico
  5. Em Tipo de Recurso, selecione Instância
  6. Em Instância, selecione a instância EC2 à qual deseja associar o IP.
  7. (Opcional) Em Endereço IP privado, especifique um IP privado específico da instância caso ela possua mais de um.
  8. Clique em Associar.

3. Associar um endereço IP elástico em uma Interface de Rede​

  1. Abra o console do Amazon EC2 em https://console.aws.amazon.com/ec2/
  2. No painel de navegação, escolha Rede e Segurança e depois IPs elásticos
  3. Selecione o endereço IP elástico que deseja associar.
  4. Clique em Ações -> Associar endereço IP elástico
  5. Em Tipo de Recurso, selecione Interface de rede
  6. Em Interface de rede, selecione a interface de rede à qual deseja associar o IP.
  7. (Opcional) Em Endereço IP privado, especifique um IP privado específico da instância caso ela possua mais de um.
  8. Clique em Associar.

4. Desassociar um endereço IP elástico​

  1. Abra o console do Amazon EC2 em https://console.aws.amazon.com/ec2/
  2. No painel de navegação, escolha Rede e Segurança e depois IPs elásticos
  3. Selecione o endereço IP elástico a ser desassociado e clique em Ações
  4. Clique em Desassociar endereço IP elástico.
