Volumes EBS

Este tutorial tem como objetivo orientar, de forma prática e detalhada, a criação de um volume EBS na AWS.

Ao final deste guia, você será capaz de:

  • Criar un volume EBS.
  • Anexar o volume a uma instância EC2.
  • Preparar e montar o volume no sistema operacional.

Requisitos​

Antes de criar o EBS, garanta que você tenha:

  • Uma conta AWS ativa.
  • Pelo menos uma instância EC2 para associar o volume. (Opcional, se quiser anexar na instância).
  • Permissões no IAM para criar e gerenciar volumes EBS

1. Criando um EBS na Console AWS​

  1. Abra o console do Amazon EC2: https://console.aws.amazon.com/ec2/
  2. No painel de navegação, vá até a seção Elastic Block Store e clique em Volumes
  3. Clique no botão Criar volume
  4. Em Tipo de volume, selecione o tipo desejado
    • gp3, gp2 -> Uso geral
    • io1, io2 -> Alta performance (IOPS provisionado)
    • sc1, st1 -> Otimizado para throughput
    • Magnético -> Opção mais antiga e menos comum
  5. Em Tamanho, informe a capacidade desejada do volume em GB.
  6. (Apenas para gp3, io1 e io2), defina o valor de IOPS.
  7. (Apenas para gp3), defina a Taxa de transferência desejada em MB/s.
  8. Em Zona de disponibilidade, selecione a AZ onde o volume será criado.

    Importante: Para anexar diretamente a uma instância EC2, ela precisa estar na mesma AZ.

  9. Em ÌD do snapshot`, escolha:
    • Valor padrão para criar um volume vazio.
    • Um snapshot existente para criar o volume a partir dele
  10. (Se usar snapshot), Opcionalmente, Taxa de inicialização de volume, defina a velocidade (em MB/s) para carregar os blocos do snapshot armazenado no Amazon S3.
  11. (Apenas para volumes io1 e io2), para habilitar Multi-Attach, marque a opção Habiliar Multi-Attach.
  12. Em Criptografia, defina se o volume será criptografado e selecione a chave de criptografia, se necessário.
  13. (Opcional), Em Tags, adicione pares de chave-valor para identificar o volume.
  14. Clique em Criar volume.

2. Anexando um EBS a uma instância EC2​

Dica: Certifique-se de que o volume e a instância EC2 estejam na mesma AZ, caso contrário, a opção de anexar não está disponível.

  1. Abra o console do Amazon EC2: https://console.aws.amazon.com/ec2/
  2. No painel de navegação, vá até a seção Elastic Block Store e clique em Volumes
  3. Selecione o volume que deseja anexar.
  4. Clique em Ações > Associar volume
  5. Em Instancia, selecione ou insira o ID da instância EC2 que receberá o volume.
  6. Em Nome do dispositivo, informe o caminho do dispositivo (por exemplo: /dev/sdf) ou utilize o valor sugerido pela AWS.
  7. Clique em Associar volume.

3. Preparando e montando um volume EBS na Instância EC2 (Linux)​

  1. Conectar na Instância via SSH
  2. Identificar o volume com o comando:
lsblk

Exemplo de saída:

NAME          MAJ:MIN RM SIZE RO TYPE MOUNTPOINTS
nvme0n1       259:0    0   8G  0 disk 
├─nvme0n1p1   259:1    0   8G  0 part /
└─nvme0n1p128 259:3    0  10M  0 part /boot/efi
nvme1n1       259:4    0   2G  0 disk

O disco nvme1n1 é o volume recém-anexado e ainda sem partições

  1. Criar o sistema de arquivos:
sudo mkfs -t ext4 /dev/nvme1n1
  1. Criar um ponto de montagem:
sudo mkdir /mnt/ebs
  1. Montar o volume:
sudo mount /dev/nvme1n1 /mnt/ebs
  1. Verificar o disco montado:
df -hT

Exemplo de saída:

Filesystem     Type  Size  Used Avail Use% Mounted on
/dev/nvme1n1   ext4  2.0G   24K  1.9G   1% /mnt/ebs

Opicional - Montar automaticamente no boot​

  1. Obtenha o UUID
sudo blkid -s UUID /dev/nvme1n1

Exemplo de saída:

/dev/nvme1n1: UUID="00ee66b6-f61b-4a1d-a473-288eb678df54"
  1. Edite o arquivo /etc/fstab:
sudo nano /etc/fstab
  1. Adicione a linha:
UUID=00ee66b6-f61b-4a1d-a473-288eb678df54 /mnt/ebs ext4 defaults,nofail 0 2
  1. Teste a configuração:
sudo umount /mnt/ebs
sudo mount -a
df -hT

4. Aumentando o tamanho do volume EBS​

  1. Abra o console do Amazon EC2: https://console.aws.amazon.com/ec2/
  2. No painel de navegação, vá até Elastic Block Store > Volumes
  3. Selecione o volume que deseja aumentar.
  4. Clique em Ações > Modificar volume
  5. No campo Tamanho (GB), insira o novo valor desejado (o tamanho deve ser maior que o atual).
  6. Clique em Modificar e depois Modificar para confirmar.
  7. Aguarde o status mudar para Disponível (pode demorar alguns minutos)

Você pode aumentar o volume mesmo com a instância em execução, sem precisar reiniciar.

4.1. Ajustando o sistema de arquivos no Linux​

Depois de aumentar o volume no console, é necessário expandir a partição e o sistema de arquivos para usar o novo espaço.

  1. Verificar o tamanho atual
df -hT
  1. Identificar o dispositivo
lsblk

Exemplo de saída:

/dev/nvme1n1     ext4      2.0G   24K  1.8G   1% /mnt/ebs
  1. Redimensionar o sistema de arquivos
sudo resize2fs /dev/nvme1n1
  1. Confirmar o novo tamanho
df -hT

Saída esperada

Filesystem     Type  Size  Used Avail Use% Mounted on
/dev/nvme1n1   ext4   10G   24K   9.9G   1% /mnt/ebs

5. Criando um snapshot do volume EBS​

  1. Abra o console do Amazon EC2: https://console.aws.amazon.com/ec2/
  2. No painel de navegação, vá até Elastic Block Store > Volumes
  3. Selecione o volume que deseja criar um snapshot.

    Certifique-se de que é o volume correto, principalmente se houver múltiplos volumes na instância.

  4. Clique em Ações > Criar snapshot
  5. Na tela de criação:
    • Descrição: Adicione uma descrição clara para o snapshot.
    • Tags (Opcional): Adicione tags para identificar o snapshot.
  6. Clique em Criar snapshot
  7. Vá em Elastic Block Store > Snapshots para acompanhar o progresso.

    O status mudará de Pendente para Concluído quando finalizado.

6. Copiando um snapshot do volume EBS para outra região​

Esse processo é útil para:

  • Replicar dados para recuperação de desastres (DR).
  • Criar volumes EBS em diferentes regiões.
  • Manter backups distribuídos geograficamente.
  1. Abra o console do Amazon EC2: https://console.aws.amazon.com/ec2/
  2. No painel de navegação, vá até Elastic Block Store > Snapshots
  3. Selecione o snapshot que deseja copiar.
  4. Clique em Ações > Copiar snapshot.
  5. Na tela de cópia:
    • Região de destino: Selecione a região para onde deseja copiar o snapshot.
    • Descrição: Adicione uma descrição para o novo snapshot.
    • Criptografia:
      • Como o snapshot original já criptografado, a cópia também será criptografada.
      • Você pode manter a mesma chave KMS ou escolher outra.
    • Tags (Opcional): Adicione tags para identificar o novo snapshot.
  6. Clique em Copiar snapshot
  7. Na região de destino, vá até Elastic Block Store > Snapshots para acompanhar o progresso.

A cópia do snapshot poderá levar vários minutos para ser concluída.

Observação: Se escolher outra chave de criptografia KMS, garanta que ela exista na região de destino.
