Elastic Network Interface (ENI)

O que é uma Elastic Network Interface (ENI)​

Uma Elastic Network Interface (ENI) é um componente lógico de rede dentro de uma VPC que representa uma placa de rede virtual. Ela pode ser criada, configurada e anexada a instância EC2, permitindo flexibilidade e controle avançado de rede.

No console e na API da AWS, o termo usado é apenas Interface de rede, mas sempre se refere à ENI.

Você pode:

  • Criar ENIs separadas da instância.
  • Anexar e desanexar ENIs de instâncias dentro da mesma zona de disponibilidade.
  • Mover uma ENI de uma instância para outra sem mudar sua configuração (endereço IP, SGs, etc).
  • Associar múltiplos endereços IP (IPv4 e IPv6) a uma ENI.
  • Associar **Elastic IPs a cada IP privado.

Atributos da interface de rede​

Uma interface de rede pode incluir os seguintes atributos:

  • Um endereço IPv4 privado primário.
  • Um endereço IPv6 primário.
  • Endereços IPv4 secundários.
  • Endereços IPv6 secundários.
  • Um EIP por endereço IPv4 privado.
  • Um endereço IPv4 público.
  • Grupos de segurança (Security Groups)
  • Endereço MAC fixo.
  • Verificação de origem/destino (Source/Dest Check).
  • Descrição.
  • Integração com logs de fluxo da VPC para monitoramento de tráfego.

Conceitos importantes​

Interface de rede primária​

Cada instância EC2 tem uma ENI primária por padrão (eth0), criada junto com a instância. Essa ENI não pode ser desanexada da instância.

Interfaces de rede secundárias​

Você pode criar e anexar ENIs secundárias (ex: eth1, eth2,...) em instâncias compatíveis. O número máximo de ENIs por instância depende do tipo de instância.

ENIs secundárias são úteis para:

  • Serviços multi-homed (mais de uma rede).
  • Separação de tráfego entre aplicações.
  • Failover automático com reassociação de ENIs.

IPs públicos e privados​

  • Toda ENI recebe um IPv4 privado primário de sub-rede.
  • Pode ter IPv4 privados secundários (reutilizáveis entre instâncias).
  • Pode ter IPv6 primário e secundários, se sua VPC/sub-rede tiver blocos IPv6.
  • Pode receber um IP público automaticamente com base nas configurações da sub-rede.
  • Pode ter Elastic IPs associados aos endereços IPv4 privados.

Comportamento com parada e término​

  • IP público (não EIP) é liberado automaticamente quando a instância é parada ou encerrada.
  • EIPs continuam associadas até que você os libere manualmente.
  • Você pode configurar o comportamente de encerramento da ENI:
    • Se ela será excluída automaticamente ao terminar a instância.
    • Ou se permanecerá intacta para uso futuro.

Verificação de origem/destino​

Por padrão, a ENI só aceita tráfego destinado à própria instância.

Para permitir roteamento, NAT, Firewalls ou proxies, desative a verificação de origem/destino.

aws ec2 modify-network-interface-attribute \
  --network-interface-id eni-xxxxxxxx \
  --no-source-dest-check

Placas de Rede (Network Cards)​

A maioria dos tipso de instâncias suporta apenas uma única placa de rede. No entanto, existem tipos de instâncias que oferecem suporte a múltiplas placas de rede, permitindo maior largura de banda (acima de 100 Gbps) e maior taxa de pacotes.

Quando você anexa uma interface de rede a uma instância compatível com múltiplas placas, pode especificar em qual placa ela será alocada. A ENI primária sempre ocupa o índice 0 da primeira placa de rede.

Importante: ENIs do tipo EFA (Elastic Fabric Adapter) ou exclusivamente EFA contam como uma interface por placa. Só é possível alocar uma EFA por placa, e a ENI primária não pode ser do tipo exclusivamente EFA.
