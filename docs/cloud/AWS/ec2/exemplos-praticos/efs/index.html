EFS

Este tutorial ensina, de forma prática, como criar um Amazon Elastic File System (EFS) e montá-lo em instâncias EC2, permitindo acesso simultâneo e compartilhado a arquivos em múltiplas zonas de disponibilidade.

1. Criando o sistema de arquivos EFS​

  1. Abra o console do Amazon EC2: https://console.aws.amazon.com/efs/
  2. Clique em Criar sistema de arquivos

Opção 1: Configuração Rápida​

  1. Nome: Identificação do EFS
  2. VPC: Escolha a VPC onde suas instâncias EC2 estão criadas.
  • A configuração padrão cria um EFS Regional
  • Políticas de ciclo de vida ativado por padrão
  • Criptografia de dados em repouso ativada por padrão
  • Modo de taxa de transferência ativado por padrão
  • Modo de desempenho de uso geral

Opção 2: Configuração Personalizada​

Ao clicar em Personalizar, você poderá ajustar as configurações avançadas:

Passo 1 - Configurações básicas:​

  1. No campo Nome, insira um nome para identificar o EFS.
  2. No campo Tipo de sistema de arquivos, selecione Regional: ou One Zone:
    • Regional: No próximo passo será exibida a opção para selecionar as Zonas de Disponibilidade (AZs) onde o EFS será criado.
    • One Zone: Será exibido o campo para escolher uma única AZ onde o EFS será criado.
  3. Em Backups automáticos a opção vem habilitada por padrão.

    Você pode desmarcar se não deseja que o EFS particice do AWS Backup.

  4. Na configuração Gerenciamento de ciclo de vida:, define as transições automáticas de armazenamento:
    • Transição para IA: Move para Infrequent Access após 30 dias sem acesso (padrão).
    • Transição para Archive: Move para a classe Archive após 90 dias sem acesso (padrão).
    • Retorno ao padão: Move os arquivos de volta para a classe Standard (padrão: nenhum retorno configurado).
  5. No campo Criptografia selecione se o EFS será criptografado (padrão: habilitado com chave gerenciada pela AWS).
  6. Na configuração Modo de taxa de transferência, selecione:
    • Elástico (Recomendado): Escala automaticamente conforme a demanda.
    • Provisionado: Define manualmente a taxa de throughput desejada.
  7. Na configuração Modo de desempenho, selecione:
    • Uso geral (Recomendado): Latência baixa, ideal para maioria dos casos.
    • E/S Máxima: Maior throughput e IOPS, mas com latência mais alta (indicado para cargas muito concorridas).

Passo 2 - Configurações de rede:​

  1. Zona de Disponibilidade: Selecione a AZ onde deseja criar o destino de montagem, crie destinos em todas as AZs que terão instâncias acessando o EFS.

  2. ID da sub-rede: Escolha a subnet que pertence à AZ selecionada.

  3. Tipo de endereço IP:

    • Somente IPv4: Padrão e compatível na maioria dos casos.
    • IPv4 e IPv6 (Pilha Dupla): Escolha essa opção caso sua VPC e instância estiverem configuradas para IPv4 e IPv6, você pode habilitar.
    • Somente IPv6: Usar apenas se não houver necessidade de IPv4.

  4. Endereço IPv4 (Opcional):

    • Pode ser deixado em branco para atribuição automática.
    • Preencha apenas se quiser um IP específico da subnet.

  5. Endereço IPv6 (Opcional):

    • Disponível apenas se o tipo de endereço suportar IPv6.
    • Deixe em branco para atribuição automática.

  6. Grupos de segurança:

    • Selecione o SG que permite o tráfego NFS (porta 2049) de/para as instâncias EC2 que irão montar o EFS.
    • O grupo de segurança deve permitir inbound e outbound para NFS, seja pelo mesmo SG ou por regras cruazadas.

Passo 3 - Configurações de Políticas de acesso​

Nesta etapa, você pode aplicar regras de segurança no próprio EFS para controlar o acesso dos clientes que tentarem montar o sistema de arquivos.

Opções de políticas​

  • Impedir acesso raiz por padrão: Bloqueia o acesso de usuários root (UID 0) nas instâncias que montarem o EFS, a menos que explicitamente permitido.

  • Impor acesso somente leitura por padrão: Faz com que todos os clientes montem o EFS em modo somente leitura, a menos que exista uma permissão explícita para escrita.

  • Impedir acesso anônino: Bloqueia acesso de clientes que não enviem credenciais NFSv4 (UID/GID).

  • Aplicar criptografia em trânsito para todos os clientes: Obriga que todas as conexões usem TLS, garantindo que os dados trafeguem criptografias entre a instância e o EFS.

Essas políticas podem ser substituídas por permissões de identidade (IAM) se configuradas para permitir ações mais amplas.

Passo 4 - Revisa as configurações​

Algumas configurações são editáveis após a criação e outras não.

  1. Após a revisão, clique em Criar para criar o sistema de arquivos

2. Montando o sistema de arquivos EFS nas Instâncias EC2​

Após criar o EFS e configurar os destinos de montagem, é hora de conectá-lo às instâncias EC2.

2.1. Montar via DNS com TLS (Segura) - Opção recomendada​

Realiza os procedimentos em todas as instâncias EC2 que deseja acessar o EFS.

  1. Criar o ponto de montagem:
sudo mkdir /mnt/efs
  1. Instalar o cliente amazon-efs-utils:
  • Amazon Linux
sudo yum install -y amazon-efs-utils
  • Ubuntu/Debian
sudo apt-get update && sudo apt-get install -y amazon-efs-utils
  1. Montar o EFS:
sudo mount -t efs -o tls fs-XXXXXXXX:/ /mnt/efs

Substitua o fs-XXXXXXXX pelo ID do seu EFS.

  1. Testar a conexão:
echo "Teste EFS" | sudo tee /mnt/efs/arquivo.txt
cat /mnt/efs/arquivo.txt

Criação Instâncias EC2​

Montando o EFS nas Instâncias EC2​

Montagem automática no boot​

Para que o EFS seja montado automaticamente após reinicialização, adicione no arquivo /etc/fstab:

sudo nano /etc/fstab
fs-XXXXXXXX:/ /mnt/efs efs _netdev,tls 0 0

Substitua o fs-XXXXXXXX pelo ID do seu EFS.
