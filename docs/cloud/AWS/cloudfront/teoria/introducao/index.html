Introdução ao Amazon CloudFront

O que é o Amazon CloudFront?​

O Amazon CloudFront é um serviço de CDN (Content Delivery Network) que distribui seu conteúdo através de uma rede global de mais de 600 pontos de presença. Quando um usuário acessa seu site, o CloudFront entrega o conteúdo a partir do servidor mais próximo geograficamente, reduzindo drasticamente a latência.

A ideia é simples: em vez de todos os usuários buscarem dados do seu servidor original (que pode estar em outro continente), eles obtêm cópias armazenadas em cache próximas a eles. Um usuário em Tóquio não precisa esperar dados viajarem do Brasil, ele recebe de um servidor em Tóquio mesmo.

Por que usar o CloudFront?​

  • Performance: Latência reduzida em requisições de cache hit.
  • Redução de Custos: Com 80-90% das requisições em cache, o servidor de origem lida com menos tráfego. A transferência de origens AWS para o CloudFront é gratuita.
  • Proteção da Origem: Absorve picos de tráfego e oferece proteção básica contra DDoS.
  • Disponibilidade Global: Conteúdo replicado globalmente garante uma boa experiência em qualquer lugar.

Conceitos Fundamentais​

Distribuição​

É a configuração que define onde procurar o conteúdo (origem) e as regras de cache. Atualmente, o CloudFront foca em distribuições padrão que suportam desde assets estáticos até implementações complexas de Continuous Deployment.

Origem (Origin)​

Onde o conteúdo está armazenado: bucket S3, EC2, Load Balancer ou qualquer servidor HTTP.

Pontos de Presença (POPs / Edege Locations)​

Datacenters globais onde o conteúdo é armazenado em cache.

Objetos​

Os arquivos que você distribui: HTML, CSS, JavaScript, Imagens, vídeos, PDFs, etc. Cada arquivo é tratado independentemente para fins de cache.

TTL (Time to Live)​

Define quanto tempo um objeto permanece em cache antes de expirar.

Como Funciona (Resumo)​

  1. Usuário faz requisição -> DNS roteia para POP mais próximo
  2. POP verifica se tem o arquivo em cache e se está válido
  3. Se sim -> entrega imediatamente (10-50ms)
  4. Se não -> busca da origem -> armazena em cache -> entrega ao usuário (200-500ms primeira vez)
  5. Próximas requisições são rápidas pois está em cache

Preços​

Você paga por:

  • Transferência de dados: Do CloudFront para usuários (varia por região)
  • Requisições HTTP/HTTPS: Quantidade de requisições processadas
  • Gratuito: Transferência de origens AWS para CloudFront
  • Friee Tier: 1 TB de transferência + 10 milhões de requisições/mês por 12 meses

Casos de Uso Comuns​

  • Sites e Apps Web: Acelerar entrega de assets estáticos (imagens, CSS, JS) e até páginas completas
  • E-commerce: Distribuir catálogo de produtos, imagens, descrições globalmente
  • Streaming de Vídeo: VOD (Vídeo sob demanda) e live streaming com protocolos HLS/DASH
  • APIs: Cachear respostas de APIs que não mudam por usuário, além de otimizações de rede mesmo para conteúdo dinâmico
  • Downloads: Distribuir arquivos grandes (software, updates) eficientemente
  • Proteção: Camada adicional de segurança com AWS WAF e proteção DDoS

Quando usar o CloudFront?​

Use se:

  • Usuários estão distribuídos geograficamente
  • Quer melhorar performance globalmente
  • Precisa reduzir carga no servidor de origem
  • Trabalha com conteúdo estático (imagens, vídeos, CSS, JS)
  • Quer proteção adicional contra DDoS

Pode não precisar se:

  • Todos os usuários estão na mesma região que seu servidor
  • Conteúdo é 100% dinâmico e único por usuário
  • Volume de tráfego é muito baixo (< 100 visitas/dia)

Integração AWS​

CloudFront se integra nativamente com:

  • S3: Hospedar conteúdo estático com Origin Access Control
  • ACM: Certificados SSL/TLS gratuitos
  • Route 53: Gerenciamento de DNS
  • CloudWatch: Métricas e monitoramento
  • WAF: Firewall de aplicação web
  • Lambda@Edge: Executar código nas edge locations
