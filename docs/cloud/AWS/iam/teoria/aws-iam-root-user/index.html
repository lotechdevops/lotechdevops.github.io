Usuário-Raiz da Conta

O que é o Usuário-Raiz?​

Ao criar uma conta AWS, é gerada automaticamente uma identidade de login com acesso total e irrestrito a todos os serviços e recursos da conta. Essa identidade é conhecida como usuário-raiz.

O login do usuário-raiz utiliza o e-mail e a senha cadastrados na criação da conta AWS. Ele não é gerenciado pelo IAM e não pode ser excluído ou restringido por políticas IAM.

Por que não usar o Usuário-Raiz no dia a dia?​

O usuário-raiz possui permissões críticas que podem impactar gravemente a conta se usadas indevidamente. Por isso:

  • Nunca compartilhe as credenciais do usuário-raiz
  • Ative MFA imediatamente
  • Evite usá-lo para tarefas operacionais
  • Crie um usuário IAM com permissões administrativas para uso cotidiano

Quando usar o Usuário-Raiz​

O uso do usuário-raiz deve ser restrito a ações específicas que exigem privilégios totais e não podem ser realizadas por usuários IAM, mesmo com permissão AdministratorAccess.

Tarefas de Gerenciamento de Conta​

  • Alterar o e-mail ou senha da conta AWS
  • Fechar ou excluir a conta AWS
  • Restaurar permissões quando o único usuário IAM administrador perde acesso

Tarefas de Cobrança e Faturamento​

  • Ativar o acesso IAM ao console de faturamento
  • Visualizar faturas de impostos específicos
  • Alterar as configurações de pagamento ou plano de suporte

Tarefas Técnicas Específicas​

ServiçoAção Crítica Permitida Apenas ao Usuário-Raiz
S3Editar políticas com Deny all, ativar MFA Delete
SQSModificar políticas bloqueadas globalmente
EC2Cadastrar como vendedor no AWS Marketplace
KMSRecuperar chaves via suporte da AWS

Como Proteger o Usuário-Raiz​

A segurança do usuário-raiz é fundamental para a proteção da conta. Algumas medidas obrigatórias:

1. Habilite o MFA (Autenticação Multifator)​

  • Use MFA baseado em aplicativo (TOTP) ou dispositivo físico (U2F)
  • Habilite logo após a criação da conta

2. Monitore o Uso do Usuário-Raiz​

  • Use o AWS CloudTrail para auditar ações
  • Crie regras no Amazon EventBridge para alertar logins
  • Ative notificações por SNS para eventos envolvendo o usuário-raiz

3. Guarde as Credenciais com Segurança​

  • Nunca use o e-mail de uso pessoal para o usuário-raiz
  • Armazene as credenciais em local seguro e fora do alcance de terceiros
  • Faça revisões periódicas para garantir que ele não esteja sendo utilizado inadvertidamente

Conclusão​

O usuário-raiz é a chave-mestra da conta AWS. Seu uso deve ser limitado, monitorado e protegido com rigor máximo. Bons profissionais criam usuários IAM administrativos e reservam o usuário-raiz apenas para emergências e tarefas críticas.

Dica prática: Configure alertas para qualquer uso do usuário-raiz. Em ambientes corporativos, o uso não autorizado pode indicar um incidente grave de segurança.
