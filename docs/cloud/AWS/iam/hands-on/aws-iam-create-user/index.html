Criação de Usuário

Objetivo​

Criar usuários IAM com diferentes níveis de acesso utilizando o AWS Console, habilitar MFA e testar o login com segurança.

Pré-requisitos​

  • Conta AWS ativa
  • Acesso ao IAM com permissões administrativas

Etapas​

1. Acessar o Console IAM​

  1. Faça login no [Console AWS] (https://console.aws.amazon.com/)
  2. Pesquise pelo serviço IAM no meu de busca e clique sobre o serviço.

2. Criar Novo Usuário​

  1. Clique em Usuários no menu lateral a esquerda.
  2. Clique em Criar usuario
  3. Defina o nome do usuário
  4. Marque as opções:
    • Fornecer acesso para os usuários ao Console de Gerenciamento da AWS
    • Quero criar um usuário do IAM
  5. Gere uma senha automaticamente ou crie um senha personalizada
    • Marque a opção "Usuários devem criar uma nova senha na próxima sessão" (recomendado)

3. Definir permissões​

Existem 3 opções de anexar permissões:

  • Adicionar usuário ao grupo: Você pode adicionar um usuário a um grupo existente.
  • Copiar permissões: Quando existem outros usuários já criados e quer copiar as permissões de algum usuário, selecione o nome do usuário.
  • Anexar políticas diretamente: Quando não existe nenhum grupo criado e não quer copiar as permissões de nenhum usuário, você pode anexar um política direta para o usuário.
  1. Na tela de Permissões, selecione a opção Anexar políticas diretamente
  2. Selecione a política desejada, no nosso exemplo iremos selecionar a política PowerUserAccess
  3. Revise as configurações e Adicione tags como (Opcional):
    • key: Department, value: DevOps
  4. Clique em Criar usuário
  5. Anote ou baixe as credenciais temporárias (URL de login + nome do usuário + senha inicial).

⚠️ Essa senha só aparece uma vez.

4. Testar Login​

  1. Acesse o link de login personalizado.
    • No nosso exemplo acessaremos: https://lotechawstreinamento.signin.aws.amazon.com/console
  2. Faça login com o usuário criado
    • No nosso exemplo criamos o usuário: Lorenzo
  3. Insira a senha inicial e redefina.

5. Configurar MFA​

  1. Vá em IAM > Usuários > [Usuario Criado]
  2. Acesse a aba Credenciais de segurança
  3. Clique em Atribuir dispositivo com MFA
  4. Escolha uma das três opções disponíveis:
    • Chave de acesso ou chave de segurança
    • Aplicação autenticadora (Ex de uso: Google Authenticator, Microsoft Authenticator)
    • Token TOTP de hardware

No nosso exemplo de configuração, iremos utilizar a opção Aplicação autenticadora

  1. Insere um nome do dispositivo. (Ex: awstreinamento_console)
  2. Clique em Próximo
  3. Clique em Mostrar código QR
  4. Abre o app no celular e lê o QRcode gerado.
  5. Insere os códigos gerados no app nos campos Código MFA 1 e Código MFA 2
  6. Clique em Adicionar MFA
