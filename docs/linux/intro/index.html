Linux

O Linux é o sistema operacional por trás de quase tudo que um profissional de DevOps e Cloud opera: servidores, instâncias na nuvem, nós de cluster Kubernetes e a base dos containers. Entender o sistema por baixo é o que permite diagnosticar um problema em vez de apenas seguir um tutorial.

Esta seção é uma trilha em ordem de dependência: cada tema usa o que foi visto no anterior, e o caminho termina na base de containers e Kubernetes.

Como esta seção funciona​

Cada artigo combina teoria e prática:

  • Teoria: o que é, por que existe e como funciona, sempre ligado a situações reais de operação.
  • Prática: comandos e exemplos para reproduzir no seu laboratório, com a saída esperada e os erros mais comuns.
  • Laboratórios dedicados: nos temas mais complexos (vários passos encadeados), há uma página de laboratório à parte, com vídeos curtos.
  • Resumo para anotar: ao final de cada artigo, uma lista com os conceitos e comandos principais para consulta rápida.
Aprenda fazendo

Leia uma seção, execute os comandos no terminal e só então avance. Reproduzir os exemplos e errar de propósito é o que fixa o conteúdo.

Seu laboratório​

Para acompanhar os exemplos, o ideal é ter um ambiente descartável:

  • Uma máquina virtual (VirtualBox, VMware, KVM ou uma instância na nuvem) com Ubuntu Server LTS ou Rocky Linux
  • Um snapshot do estado inicial, para voltar atrás depois de experimentos que quebram o sistema
  • Acesso a um usuário com sudo
Não pratique em produção

Vários exemplos alteram permissões, serviços e configurações de rede de propósito. Faça tudo em um laboratório, nunca em um servidor em uso.

Sobre os exemplos​

Os comandos e exemplos foram testados em máquinas virtuais de laboratório. Quando o comportamento muda entre distribuições (por exemplo, o grupo sudo no Debian e Ubuntu e wheel no RHEL e derivadas), o artigo indica a diferença.
