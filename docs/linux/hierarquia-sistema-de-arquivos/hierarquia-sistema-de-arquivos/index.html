Hierarquia do Sistema de Arquivos no Linux — Entendendo o FHS

O FHS (Filesystem Hierarchy Standard) é uma especificação que define como os diretórios e seus conteúdos devem ser organizados nos sistemas Linux. Ele promove a padronização, facilitando a navegação, a manutenção e o desenvolvimento de aplicações compatíveis entre distribuições.

Neste post, vamos explorar os principais diretórios definidos pelo FHS, explicando suas funções e destacando os subdirtórios mais importantes.

1. / - Raiz do sistema​

A raiz ( / ) é o ponto inicial de todo o sistema de arquivos. Todos os outros diretórios são ramificações dela.

2. /bin/ - Binários essenciais do sistema​

Armazena comandos básicos usados por todos os usuários e necessários para o sistema iniciar e operar em modo de manutenção.

Subdiretórios​

  • Normalmente não possui subdiretórios; os binários estão diretamente no /bin.

Exemplos de arquivos​

  • bash - shell padrão.
  • cat - concatena arquivos.
  • cp, mv, rm - comandos de manipulação de arquivos.
  • echo - exibe texto.
  • ps - visualiza processos.
  • kill - envia sinais a processos.

📌 Observação: Em algumas distribuições modernas, /bin é apenas um link simbólico para /usr/bin.

3. /boot/ - Inicialização do sistema​

Armazena tudo que é necessário para carregar o sistema operacional antes do kernel assumir o controle.

Arquivos e subdiretórios importantes​

  • vmlinuz-* - kernel linux comprimido.
  • initrd.img-* ou initramfs-* - imagem de disco usada para preparar o ambiente inicial.
  • grub/ - diretório com os arquivos de configuração do GRUB.

Dentro de /boot/grub (ou /boot/efi em UEFI)​

  • grub.cfg - configurações de inicializaçaão (menu do boot).
  • fonts/, locale/, themes/ - temas, idiomas e fontes do GRUB.

4. /dev/ - Dispositivo do sistema​

Pasta virtual que representa todos os dispositivos de hardware e interfaces do kernal

Subdiretórios importantes​

  • pts/ - pseudoterminais (ex: sessões de terminal).
  • shm/ - memória compartilhada usada por processos.
  • disk/, block/, char/ - dispositivos de bloco e de caractere.
  • mapper/ - dispositivos gerenciados pelo LVM (Logical Volume Manager).

Exemplos de arquivos​

  • /dev/sda, /dev/sdb - discos físicos.
  • dev/tty - terminal padrão.
  • /dev/null - descarte de saída.
  • /dev/random, /dev/urandom - geradores de entropia.

5. /etc/ - Arquivos de configuração​

Contém todas as configurações do sistema, serviços, rede, autenticação, usuários, etc.

Subdiretórios e arquivos críticos​

  • /etc/network/interfaces - configuração de rede (Debian).
  • /etc/sysconfig/network-scripts - configuração de rede (RHEL, CentOS).
  • /etc/hostname - nome da máquina.
  • /etc/hosts - resolução local de nomes.
  • /etc/resolv.conf - configuração de DNS.
  • /etc/passwd, /etc/shadow - base de dados de usuários e senhas.
  • /etc/fstab - pontos de montagem persistentes.
  • /etc/ssh/ - configurações do SSH (sshd_config, ssh_config).
  • /etc/systemd/system - unidades personalizadas do systemd.
  • /etc/crontab e /etc/cron.* - agendamento de tarefas.

6. /home/ - Diretório dos usuários​

Cada usuário do sistema tem um diretório dentro de /home, contendo seus arquivos, configurações pessoais e histórico.

Estrutura básica​

  • /home/neto
    • Documents/, Downloads/, Pictures/.
    • .bashrc, .profile - scripts de inicialização do shell.
    • .ssh - chaves SSH e arquivos de configuração.

⚠️ Diretório de uso exclusivo do usuário. O root não armazena nada aqui.

7. /lib/ & /lib64/ - Bibliotecas compartilhadas​

Contêm bibliotecas essenciais para o carregamento dos binários em /bin e /sbin.

Subdiretórios comuns​

  • /lib/modules - módulos do kernel.
  • /lib/systemd - binários e unidades do systemd.

Exemplos de arquivos​

  • libc.so.6 - biblioteca C padrão.
  • ld-linux.so.* - carregador dinâmico.

💡 /lib64/ contém bibliotecas para sistemas 64 bits.

8. /media/ - Dispositivos removíveis​

Diretório usado por ambientes gráficos para montar automáticamente dispositivos conectados ao sistema.

Estrutura​

  • /media/neto/USB_DRIVE/
  • /media/cdrom/

Criado automaticamente pelo udisks ou por ambientes como GNOME/KDE.

9. /mnt/ - Pontos de montagem manual​

Usado para montagens temporárias manuais de administradores.

Exemplo​

sudo mount /dev/sdb1/ /mnt/pendrive

10. /opt/ - Pacotes de software de terceiros​

Diretório reservado para softwares externos ao sistema operacional.

Estruturas​

  • /opt/google/chrome
  • /opt/vmware/
  • /opt/docker/

11. /proc/ - Sistema de arquivos virtual​

Diretório gerado em tempo real, que exibe informações do kernel e dos processos ativos.

Subdiretórios​

  • /proc/cpuinfo - CPU
  • /proc/meminfo - Memória RAM
  • /proc/uptime - tempo de atividade do sistema
  • /proc/[PID] - detalhes de cada processo.
    • cmdline, environ, fd/, cwd

12. /root/ - Home do usuário root​

Similar ao /home/neto, mas reservado para o superusuário.

Importante: é diferente de / (raiz do sistema).

13. /run/ - Estado temporário do sistema​

Armazena arquivos e sockets que representam o estado atual do sistema, como PIDs, locks e sockets de serviços.

Exemplos​

  • /run/systemd/ - dados internos do systemd
  • /run/nginx.pid - PID do processo nginx

14. /sbin/ - Comandos administrativos​

Armazena binários essenciais de administração do sistema (normalmente exigem root).

Exemplos​

  • fsck - verificação de sistema de arquivos.
  • reboot, shutdown
  • mount, umount
  • iptables, ip

📌 Como /bin, muitas distros fazem dele um link simbólico para /usr/sbin.

15. /srv/ - Dados servidos por serviços​

Contém dados usados por serviços de rede como HTTP, FTP, etc.

Exemplos​

  • /srv/www/neto.blog/ - páginas de um site.
  • /srv/ftp/ - arquivos disponíveis para FTP

16. /tmp/ - Arquivos temporários​

Espaço para arquivos temporários gerados por aplicações Pode ser limpo automaticamente.

Importante: acessível a todos os usuários, mas isolado por permissões (sticky bit).

17. /usr/ - Utilitários e bibliotecas de usuários​

Local de instalação de aplicações e bibliotecas não essenciais ao boot.

Subdiretórios​

  • /usr/bin/ - binários principais do sistema.
  • /usr/sbin/ - ferramentas administrativas.
  • /usr/lib/, /usr/lib64/ - bibliotecas.
  • /usr/share/ - arquivos compartilhados como:
    • /usr/share/man/ - páginas de manual
    • /usr/share/doc/ - documentação.
  • /usr/local/ - software instalado localmente pelo usuários.

18. /var/ - Dados variáveis​

Armazena dados que crescem com o uso do sistema: logs, spool de impressão, e-mails, cache.

Subdiretórios importantes​

  • /var/log/ - arquivos de log do sistema:
    • syslog, auth.log, messages
  • /var/spool/ - filas de tarefas:
    • cron, mail, cups
  • /var/cache/ - cache de pacotes e navegadores.
  • /var/tmp/ - arquivos temporários persistentes entre boots.

19. /sys/ - Interface com o Kernel via sysfs​

É um sistema de arquivos virtual (como o /proc) introduzido no kernel 2.6. Ele expõe informações e interfaces em tempo real sobre dispositivos, drivers e subsistemas gerenciados pelo kernel.

📌 Montado automaticamente em tempo de boot, com:

mount -t sysfs sysfs /sys

Estrutura dos principais diretórios​

  • /sys/class/ - Representa classes de dispositivos como net, power_supply, input.
  • /sys/block/ - Lista os dispositivos de bloco (ex: HDs, SSDs, partições).
  • /sys/bus/ - Representa os buses do sistema, como USB, PCI, SCSI, etc.
  • /sys/devices/ - Mapeamento físico de dispositivos e sua topologia no sistema.
  • /sys/firmware/ - Informações sobre o firmware (ex: ACPI, EFI, DMI).
  • /sys/kernel/ - Parâmetros configuráveis do kernel, eventos e subsistemas internos.
  • /sys/module/ - Lista todos os módulos carregados no kernel, com parâmetros.
  • /sys/fs/ - Informações sobre os sistemas de arquivos registrados (ex: cgroups).
